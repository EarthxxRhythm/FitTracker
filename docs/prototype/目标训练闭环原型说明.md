# FitTracker 目标训练闭环原型说明

版本：V2.0
日期：2026-05-23
用途：指导重新绘制项目原型图和后续 ArkUI 页面实现。

## 1. 原型原则

- 第一屏展示可执行任务，不做营销型首页。
- 页面围绕“目标配置 -> 计划生成 -> 训练执行 -> 训练复盘 -> 下次调整”展开。
- 动作教学和训练记录必须在训练过程中低干扰呈现。
- 肌肉图谱用于探索和替换动作，不替代训练主流程。
- 首版原型以手机竖屏为主，兼顾 HarmonyOS 常见屏宽。

## 2. 一级导航

| Tab | 页面定位 | 关键入口 |
| --- | --- | --- |
| 首页 | 今日训练与进度摘要 | 开始训练、继续训练、查看计划、查看 PR |
| 计划 | 目标和周期计划管理 | 目标问卷、生成计划、训练日详情、替换动作 |
| 动作 | 动作百科和肌肉图谱 | 肌肉图谱、搜索、筛选、动作详情 |
| 训练 | 训练执行工作台 | 视频提示、组数记录、休息计时、结束训练 |
| 复盘 | 训练结果和下次建议 | 周统计、肌群覆盖、个人记录、恢复反馈 |

## 3. 首次使用原型

### 3.1 启动页

目标：建立产品定位并进入目标配置。

关键元素：

- 产品名 FitTracker。
- 简短定位：“按目标生成训练计划，记录每一次进步。”
- 主按钮：“开始配置目标”。
- 次入口：“稍后再说，使用默认计划”。

### 3.2 目标问卷页

目标：采集计划生成的核心参数。

页面分步：

1. 训练目标：增肌、减脂、力量、体态改善。
2. 训练水平：新手、规律、进阶。
3. 每周训练天数：2 到 6 天。
4. 单次训练时长：30、45、60、90 分钟。
5. 可用器械：杠铃、哑铃、绳索、固定器械、自重、弹力带。
6. 受限部位：肩、腰、膝、腕、无。

交互：

- 每步都有返回。
- 未完成必填项时下一步按钮禁用。
- 最后一步进入计划生成结果。

### 3.3 计划生成结果页

目标：让用户确认系统生成的训练计划。

关键元素：

- 计划名称。
- 每周训练日摘要。
- 重点肌群分配。
- 每天动作数量与预计时长。
- 提示：计划可稍后调整。
- 主按钮：“使用此计划”。
- 次按钮：“重新配置目标”。

## 4. 首页原型

目标：让用户快速知道今天是否训练，以及该做什么。

模块：

- 顶部问候和当前目标。
- 今日训练卡片：训练日名称、预计时长、重点肌群、动作数量。
- 主按钮：开始训练。
- 目标进度：本周完成次数、周目标。
- 最近 PR：动作名、估算 1RM 或最佳组。
- 快捷入口：计划、动作库、复盘。

状态：

- 今日有训练。
- 今日休息。
- 有未完成训练草稿。
- 尚未生成计划。

## 5. 计划原型

### 5.1 计划总览页

模块：

- 当前计划名称和目标。
- 周计划日历。
- 训练日卡片：重点肌群、动作数、预计时长。
- 操作：重新生成、编辑目标、查看历史计划。

### 5.2 训练日详情页

模块：

- 训练日名称。
- 重点肌群。
- 动作列表。
- 每个动作展示：名称、器械、目标组次、替代动作入口。
- 按钮：开始本日训练。

### 5.3 动作替换页

目标：当用户因器械或身体状态无法完成动作时，提供可替换动作。

模块：

- 当前动作摘要。
- 替代动作列表。
- 替代原因标签：同肌群、同器械、低风险、低难度。
- 替换后影响提示。

## 6. 动作原型

### 6.1 肌肉图谱页

目标：按身体区域探索动作。

模块：

- 人体肌肉图谱区域。
- 肌群列表。
- 最近查看动作。
- 热门动作。

交互：

- 点击肌群进入动作列表。
- 切换正面/背面。

### 6.2 动作列表页

模块：

- 搜索框。
- 筛选栏：肌群、器械、难度、目标。
- 动作卡片：名称、主要肌群、器械、难度、收藏。

### 6.3 动作详情页

模块：

- 视频或视频占位。
- 动作名称、肌群、器械、难度。
- 标签页：步骤、要领、常见错误、安全提示、替代动作。
- 个人记录摘要。
- 操作：加入计划、替换当前动作、收藏。

## 7. 训练原型

### 7.1 训练预览页

模块：

- 今日训练名称。
- 预计时长和重点肌群。
- 动作列表。
- 提醒：可在训练中替换动作。
- 主按钮：开始训练。

### 7.2 训练中记录页

模块：

- 顶部计时器。
- 当前动作视频缩略区域。
- 动作要领折叠区。
- 组数记录表：重量、次数、RPE、完成状态。
- 休息计时器。
- 操作：添加组、替换动作、跳过动作、结束训练。

状态：

- 正在训练。
- 休息中。
- 当前动作完成。
- 新个人记录。
- 网络不可用但本地记录正常。

### 7.3 训练完成总结页

模块：

- 完成率。
- 训练时长。
- 总组数。
- 总容量。
- 新 PR。
- 疲劳反馈。
- 主按钮：查看复盘。

## 8. 复盘原型

### 8.1 复盘首页

模块：

- 本周训练次数。
- 本周总容量。
- 肌群覆盖。
- 最近 PR。
- 下次训练建议。

### 8.2 肌群覆盖页

模块：

- 肌群覆盖图。
- 每个肌群最近训练时间。
- 计划覆盖与实际覆盖对比。

### 8.3 个人记录页

模块：

- 搜索动作。
- 动作 PR 列表。
- 估算 1RM。
- 最佳组详情。
- 记录日期。

## 9. 内容同步原型

入口：我的 / 设置 / 内容库。

模块：

- 当前内容版本。
- 上次更新时间。
- 检查更新按钮。
- 更新进度。
- 更新失败提示。
- 本地内容可用状态。

原则：

- 内容更新不打断训练。
- 更新失败只提示，不阻止进入动作库。

## 11. 视觉方向

- 整体风格：专业、清晰、训练工具感，不做花哨营销风。
- 信息密度：训练中页面高密度但层级清楚。
- 色彩：深色训练场景友好，使用绿色/蓝色表达进度，金色表达 PR。
- 组件：按钮、卡片、标签、分段控件、搜索栏、数据徽章、休息计时器、视频容器。
- 重点避免：大段说明文、过度装饰、复杂弹窗、训练中多层跳转。
