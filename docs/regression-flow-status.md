# Regression Flow 状态说明

当前认证链路的核心实现已经落地，并由单元测试与 ohosTest 流程测试覆盖：

- 启动页会先检查 `SessionManager.isLoggedIn()`，未登录跳转登录页，已登录再继续目标分流。
- 登录页与注册页都已接入本地认证服务、表单校验和令牌保存。
- 持久化用户、令牌恢复、按目标状态继续跳转已有 `AuthSessionFlow` 与 `AuthRoutingFlow` 覆盖。

当前这条线的后续重点不是重写认证实现，而是：

- 增加更贴近模拟器/UI 的认证回归脚本。
- 在必要时补页面级交互验证，而不是重复补底层服务逻辑。
