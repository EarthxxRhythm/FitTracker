# 旧页面治理记录

## 当前结论

当前主线以 `main_pages.json` 和 `app/AppRoutes.ets` 为准，页面已迁移到 `features/pencil/`、`features/welcome/`、`features/onboarding/`、`features/exercise/`、`features/monetization/` 和 `features/workout/`。

以下旧代码已确认无路由、无 ArkTS import、无测试引用，并已从源码中移除：

- 旧认证壳、旧首页壳和旧个人页壳
- 旧全局标签栏、统计徽章、空状态和分段控件
- 旧复盘页、旧计划详情页、旧启动页和旧训练预览/执行页
- 旧首页原型、展示服务和仅供其使用的展示组件
- 旧常量与旧 Typography 样式模块

具体历史路径保存在 `docs/archive/legacy-routes-2026-08/` 及 Git 历史中，当前文档不再把它们作为可用入口列出。

## 当前保留的兼容能力

- `features/workout/pages/WorkoutSummaryPage.ets`
- `features/workout/services/WorkoutSessionPersistenceBridgeService.ets`
- `shared/services/PersistenceFallbackService.ets`
- `shared/services/StartupContentSyncService.ets`
- `mock/SeedPlanRules.ets`

这些服务承载本地训练数据、内容源和计划种子兼容逻辑，不得仅因名称包含历史语义而删除。

## 后续规则

1. 新页面先放入对应 feature，再注册到 `main_pages.json`，最后补充 `AppRoutes` 常量。
2. 未注册且无 import 的 `.ets` 文件应在完成引用核验后删除，不能继续作为“历史壳”长期保留。
3. 持久化兼容代码不能仅因命名含有 `legacy` 就删除；必须先确认旧训练数据迁移方案。
4. 历史计划与旧路由记录统一放入 `docs/archive/`，不再作为当前路由或目录约束的来源。
