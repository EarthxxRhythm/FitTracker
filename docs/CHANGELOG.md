### 新增

- **账号体系**：手机验证码登录（未注册自动创建）、邮箱密码注册 / 登录、华为账号登录；会话快照持久化（重启保持登录）。微信 / QQ 随后接入（见「变更」）。
- **云同步（整包快照）**：本地 hash 三值决策（push / pull / none / conflict_pull，云端较新时下行）；登录成功、冷启动已登录与训练完成触发同步；云端为自建 Postgres 中的整包快照（按 userId 隔离，仅数据创建者读写）。
- **「账号与同步」页（2026-10 已下线）**：原含同步状态、上次同步时间、自动同步开关、手动同步与退出登录；现退出登录并入设置页，同步改为登录后恒定自动。
- **启动门槛**：冷启动未登录 → 登录 / 注册页；已登录 → 主壳（无论有无目标）。
- **云环境探测与降级**：原设计为「含 AGC 配置时走真实云端，缺失时降级为沙盒演示模式并在 UI 明示」；2026-10-28 后端改定为自托管 Supabase 后，此机制保留（`sandbox / supabase / agc` 三态探测，AGC 仅作历史分支）。**2026-10-28 追加标注**：后端改定后 AGC 分支已从代码删除，实为 `supabase` / `sandbox` 二态（`CloudEnvironment.ets:17` `type CloudBackend = 'supabase' | 'sandbox'`）。
- **身体数据域扩展**：新增身体档案（身高 / 性别 / 出生年份）与身体测量记录（五项围度：胸/腰/臀/臂/腿；体成分：体脂率 / 骨骼肌 / 身体水分），双端提供录入渠道；体成分与围度卡由真实数据派生（无记录时呈现诚实空态，不再显示示例值）。
- **训练整体强度（RPE）采集**：训练完成页新增「本次训练强度」采集卡（1–10 档等宽格子），按次采集整体努力程度，作为复盘页「努力程度」柱状图的唯一真数据来源。

### 变更

- 登录 / 注册页改造：手机验证码与邮箱密码双模式、验证码倒计时、协议勾选与错误提示。
- 设置页「训练数据同步」开关接入云同步；新增「账号与同步」入口行（两者随后下线，同步改为登录后恒定自动）。
- 设置模块功能落地：设置项全量持久化（Preferences）；体重单位接入用户资料并驱动身体数据页显示；周开始日驱动首页/计划/复盘/个人页的周统计与周视图；「训练中屏幕常亮」在训练中真实生效；健康数据授权改为如实显示「未接入」；版本号读取应用元数据。
- 「训练目标」引导页（GoalSetupPage）移除：无目标用户由首页空态承接。
- 隐私政策与权限声明更新：申请 `ohos.permission.INTERNET`；`docs/legal/privacy-policy.md` 增补网络与数据处理声明（AGC 认证与云数据库、数据范围、退出与清除）。
- **云同步范围扩展至身体数据**：同步快照现包含身体档案（身高/性别/出生年份）与身体数据（体重/围度/体成分），隐私政策第二、七节同步更正（此前声明「身体数据不参与云同步」已不成立）；本地备份包同步纳入 `bodyRecords` 与 `bodyMeasurements`，备份变更检测（hash 规范化）一并覆盖该两域。
- 设置模块功能落地（续）：训练提醒接入每日 19:30 提醒（当天已训练或休息日不打扰）；成就提醒（连续训练 3/7/14/30 天里程碑通知）；声音与震动接入 30ms 触觉振动；设置页文案资源化与语言切换接通（应用级语言偏好，重启后生效）。

## [1.0.0] — 2026-09-13

首个正式版本。当时的定位是「本地优先的健身训练记录工具」——所有数据只保存在设备本机、不发起网络请求。**该定位已于 1.1.0 撤销**：后端改为自托管 Supabase，登录成为强制前置，同步恒定自动。

### 新增

- **目标设置与启动分流**：冷启动按登录态分流到欢迎/登录或主壳；首启引导设置训练目标。
- **个性化训练计划**：依据目标生成当前计划，首页直接呈现"今日训练"。
- **训练流**：训练预览 → 训练执行（组次计时与记录）→ 训练完成摘要。
- **训练复盘**：历史训练、周趋势、动作 PR 下钻、肌肉分布等统计视图。
- **动作库**：动作列表、筛选、收藏与动作详情（含要点与媒体状态卡，素材内置于安装包）。
- **身体数据**：体重、体脂等记录。
- **本地账号与会话**：本地注册/登录与会话恢复。
- **数据备份与恢复**：手动导出/导入本地 JSON 备份包；承接系统备份回调（`allowToBackupRestore`）。
- **设置**：单位、语言、周开始日与各类开关的状态记录。
- **视觉主线**：按原型 1:1 重建的深色翠绿（Cool Emerald）界面，`entry/src/main/resources/base/profile/main_pages.json` 注册的 20 个页面构成完整主路由。
- **本地化资源**：补齐 `zh_CN` 与 `en_US` 应用级字符串资源目录，与默认资源键集一致。

### 已知限制

- **界面仅提供简体中文**：设置页的"English"选项当前只记录选择状态，尚未驱动界面语言切换；`zh_CN` / `en_US` 资源目录已就绪，但界面文案仍为代码内中文。
- **数据能力为本地实现**：设置页的"训练数据同步""匿名使用数据""健康数据授权"当前均为界面状态记录，未接入账号服务器、统计服务或健康数据权限（详见 `docs/legal/privacy-policy.md` 第六节）。
- **应用身份变更会改变本地数据沙箱**：`bundleName` 已由样板值 `com.example.fittracker_opencode` 替换为正式身份 `com.earthrhythm.fittracker`（`vendor` 同步由 `example` 改为 `EarthRhythm`）。**bundleName 决定应用私有沙箱路径，变更后旧身份包留下的本地数据在新包下不可见**，迁移路径详见 `docs/release/release-build-runbook.md` 第 9 节。
- **签名链未接入**：当前仅能产出 unsigned HAP，尚不具备正式签名发布能力。

### 升级提示

- 本版本为首个版本，无历史数据迁移问题。
- 从其他 `bundleName` 的构建升级（例如替换身份后）属于"新应用安装"，原沙箱数据不会自动迁移，升级前请先导出备份包。
