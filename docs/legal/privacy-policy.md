# FitTracker 隐私政策

最后更新：2026-09-13（对应应用版本 `1.0.0`，versionCode `1000000`）

本政策描述 FitTracker（以下称"本应用"）当前版本对用户数据与设备能力的**真实**处理方式。本政策中的每一项陈述都与当前代码和配置一一对应：

- 权限口径以 `entry/src/main/module.json5` 为准；
- 网络与数据行为以 `entry/src/main/ets/` 下的实现为准；
- 备份能力以 `entry/src/main/resources/base/profile/backup_config.json` 与 `entry/src/main/ets/entrybackupability/EntryBackupAbility.ets` 为准。

**我们只声明已经实现的行为，也不遗漏已经实现的行为。** 后续版本若新增任何数据采集、联网或权限申请，本政策会同步更新并在应用内提示。

## 一、核心承诺

1. **本地优先**：训练计划、训练记录、身体数据、目标设置与应用设置默认只保存在你的设备本机，不上传到任何服务器。
2. **零权限**：当前版本未向系统申请任何权限。
3. **零网络**：当前版本不发起任何网络请求，不含统计分析、广告或任何第三方数据 SDK。
4. **不收集**：我们不建立账号服务器，不采集设备标识、位置、通讯录、媒体文件或任何可识别个人身份的信息。

## 二、我们如何对待你的数据

| 数据类别 | 内容示例 | 存储位置 | 是否离开设备 |
| --- | --- | --- | --- |
| 本地账号与登录态 | 本地创建的用户名、会话 token | 应用私有沙箱（Preferences） | 否 |
| 训练计划 | 计划名称、动作、组次、周期 | 应用私有沙箱（Preferences） | 否 |
| 训练记录 | 每次训练的组次、重量、时长、完成度 | 应用私有沙箱（Preferences） | 否 |
| 身体数据 | 体重、体脂等记录 | 应用私有沙箱（Preferences） | 否 |
| 目标设置 | 目标类型、强度、周期 | 应用私有沙箱（Preferences） | 否 |
| 应用设置 | 单位、语言、周开始日、各类开关状态 | 应用私有沙箱（Preferences） | 否 |

上述数据均写入应用私有沙箱，其他应用无法直接读取。应用自身不将这些数据发送到任何远端服务。

## 三、我们不收集什么

当前版本**不**进行下列任何行为：

- 不注册、不上报设备唯一标识（OAID/AAID/UDID 等）；
- 不采集崩溃日志、埋点或使用行为统计；
- 不申请位置、通讯录、短信、相机、麦克风、相册、日历等任何敏感权限；
- 不集成广告 SDK、第三方统计 SDK 或社交分享 SDK；
- 不包含内嵌浏览器（WebView）或任何远程内容加载。

## 四、系统权限说明

`entry/src/main/module.json5` 当前**未声明任何 `ohos.permission`**，因此本应用不会向系统申请任何权限，也不会弹出权限授权弹窗。

## 五、网络访问说明

当前版本不发起任何网络请求：

- 代码中未使用网络相关 API（如 HTTP、Socket、WebSocket 等）；
- 动作演示素材（GIF、图片）随安装包内置在 `entry/src/main/resources/rawfile/` 中，运行时从本地读取，不联网下载；
- 运行时依赖为空，不引入任何会联网的第三方库。

因此，即便设备处于飞行模式或离线状态，本应用的训练记录、动作库浏览与复盘功能仍可正常使用。

## 六、关于设置页中的开关（如实说明）

设置页包含若干数据相关开关，它们当前的行为如下，**均不产生任何数据外发**：

| 设置项 | 当前实际行为 |
| --- | --- |
| 训练数据同步 | 仅记录开关状态，不连接任何服务器，不上传数据 |
| 匿名使用数据 | 仅记录开关状态，不采集、不上报任何使用数据 |
| 健康数据授权 | 仅作界面展示，未申请任何健康类权限，未读取系统健康数据 |
| 训练提醒 / 成就提醒 | 仅记录开关状态，当前未注册系统通知 |
| 声音与震动 | 仅记录开关状态 |
| 训练中屏幕常亮 | 仅记录开关状态 |

以上开关的存储同样只发生在设备本机。这些能力若在未来版本真正接入（例如接入系统通知或健康数据），本政策会先行更新并再次征得你的同意。

## 七、数据备份与迁移

- **手动备份/恢复**：你可以使用应用内备份功能，将数据导出为本地 JSON 备份包，保存在你选择的本地位置。该文件由你自行保管，应用不会自动上传。
- **系统备份**：本应用声明了 `allowToBackupRestore`，若你在系统设置中开启了云备份，操作系统可能在执行备份时把应用数据一并纳入并由**系统**上传到你自己的云账号。这一传输由系统与你的账号设置控制，应用自身不发起、不干涉。你可以通过在系统设置中关闭云备份来阻止此类传输。

## 八、数据删除

- 你可以在系统"应用管理"中清除本应用数据，或卸载本应用，这将删除设备上的全部本地数据。
- 由于应用不保留任何远端副本，清除后数据无法由我们恢复（除你自行开启的系统云备份外）。
- 建议在清除或卸载前，先使用应用内备份功能导出备份包。

## 九、未成年人

本应用是通用的健身训练记录工具，不面向 14 周岁以下儿童专门设计。若你是未成年人，请在监护人指导下使用。

## 十、政策更新

本政策可能随版本更新而调整。任何涉及数据采集、权限或联网行为的变化，都会先更新本政策并同步应用内提示，我们不会在你不知情的情况下改变数据处理方式。
