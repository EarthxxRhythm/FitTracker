- 文件仅用于历史审计、设计追溯和验收证据关联。

- 当前实现请以仓库根目录 `AGENTS.md`、`entry/src/main/resources/base/profile/main_pages.json` 和 `entry/src/main/ets/app/AppRoutes.ets` 为准。
- 原型子目录中的文件按文件名归档；原始路径和迁移背景保留在 Git 历史及对应文档内容中。
