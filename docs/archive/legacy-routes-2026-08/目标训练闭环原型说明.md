# FitTracker 目标训练闭环原型说明

## 1. 原型目标

本原型服务于 MVP 收口，不再展示完整健身工具集合，而是聚焦一条已验证链路：

目标设置 -> 今日训练首页 -> 训练预览 -> 训练执行 -> 训练复盘 -> 训练回顾 -> 调整目标。

## 2. 信息层级调整

| 旧方向 | 新方向 |
| --- | --- |
| 多入口工具集合 | 单线训练闭环 |
| 计划、动作、统计、个人中心并列 | 首页聚合今日训练和本周计划 |
| 动作库作为独立入口 | 动作详情作为训练预览的辅助信息 |
| 统计独立浏览 | 回顾页承接复盘后的反馈 |
| 占位页面先注册 | 未完成页面不进入主路由 |

## 3. 页面优先级

1. **今日训练首页**：用户打开 App 后最重要的问题是今天练什么。
2. **训练预览**：让用户在开始前确认动作、组次和休息。
3. **训练执行**：只保留完成记录，不堆叠复杂统计。
4. **训练复盘**：确认本次训练已保存。
5. **训练回顾**：让用户理解近期完成情况，并决定是否调整目标。
6. **目标设置**：首次进入和调整目标时使用，不作为日常高频入口。

## 4. 文案规范

| 页面 | 主标题 | 辅助文案方向 |
| --- | --- | --- |
| 启动页 | FitTracker | 正在准备今日训练 |
| 目标设置 | 训练目标 | 设置目标后生成本周训练计划 |
| 首页 | 今日训练 | 目标驱动的本周训练入口 |
| 预览 | 训练预览 | 开始前确认今天要练什么 |
| 执行 | 训练执行 | 按动作完成并保存记录 |
| 复盘 | 训练复盘 | 本次训练已保存 |
| 回顾 | 训练回顾 | 最近训练与目标反馈 |

## 5. 后续扩展位

- 动作详情页预留视频、肌群、器械、难度和注意事项。
- 回顾页后续可扩展肌群覆盖、个人记录和训练趋势，但不在 MVP 主导航暴露。
- 内容同步后续只服务自建动作库，不接入 MuscleWiki 官方 API。
