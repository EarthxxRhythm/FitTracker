菲特健身训练软件 V1.0
用户说明书

一、软件概述

1.1 软件简介

菲特健身训练软件（英文名 FitTracker，以下简称"本软件"）是一款运行于 HarmonyOS
平台的健身训练记录应用，采用 ArkTS 语言与 ArkUI 声明式 UI 框架开发，基于
HarmonyOS Stage 应用模型构建，目标设备类型为手机。

本软件面向力量训练与健身训练人群，解决的核心问题是：训练过程难以结构化记录、
训练效果难以量化评估。软件以"组数 × 次数 × 重量"的结构化录入替代纸质表格或
备忘录式的零散记录，并按 Epley 公式自动估算单次最大力量（1RM），将训练过程
转化为可复盘、可比对的数据。

在数据策略上，本软件采用本地存储优先的设计：训练计划、训练记录、身体数据、
目标设置与应用设置默认仅保存在设备本机的应用私有沙箱内，不强制用户注册账号，
不登录时全部核心功能均可离线使用。用户如有多设备使用需求，可选择登录云端
账号，开启跨设备同步能力。

本软件不采集设备唯一标识，不集成广告 SDK 或第三方统计 SDK，
仅申请网络访问与振动两项权限，分别用于账号登录与云同步、训练中的触觉反馈。

1.2 主要功能

本软件围绕"记录 — 复盘 — 调整"的训练闭环组织功能，具体包括：

（1）训练流程。提供从训练预览、训练执行到完成摘要的完整链路。用户在预览页
确认本次训练的动作与安排后进入执行；执行过程中逐组录入次数与重量，并可查看
当前动作的动作要领提示；训练完成后生成摘要，展示本次训练的完成情况。

（2）训练计划。内置按分化数成套的预置训练计划组，用户可浏览计划详情、预览
每日安排，并一键启用；启用后首页直接呈现"今日训练"入口，点击即可进入训练预览。

（3）训练复盘。提供历史训练列表与单次训练详情、周训练趋势、动作个人纪录
（PR）下钻、肌肉分布统计以及进阶洞察，帮助用户从数据层面判断训练是否在进步。

（4）动作库。提供动作列表与动作详情，支持按条件筛选与收藏常用动作；动作详情
包含动作要点说明与动作演示素材，素材随安装包内置，运行时不联网下载。

（5）身体数据。支持记录体重、体脂等身体数据，形成随时间的变化记录，可与训练
数据相互印证。

（6）账号与云同步（可选）。支持手机验证码、邮箱密码、华为账号三种登录方式；
登录后可开启云同步，将目标、计划、训练记录、用户资料以整包快照形式同步至
云端，用于跨设备恢复。未配置云端凭据时，软件自动进入本地演示模式，不发起
网络请求。

（7）数据备份与恢复。支持将本机数据导出为 JSON 备份包，并可从备份包导入恢复；
同时承接系统级备份回调。

（8）设置。提供重量单位、语言、周开始日，以及训练数据同步、训练中屏幕常亮等
开关项；设置项持久化保存，应用重启后保持。

1.3 技术特点

本软件基于 HarmonyOS Stage 应用模型与 ArkTS/ArkUI 声明式 UI 开发，采用模块级
单例服务架构组织业务能力；本地数据经 @kit.ArkData 提供的 Preferences 能力持久化，
云同步以整包快照方式实现；代码启用严格类型检查，不使用动态类型与反射式访问。

二、运行环境

2.1 硬件环境

运行本软件需要 HarmonyOS 智能手机，设备架构为 ARM64，系统版本为
HarmonyOS 6.0.2 及以上；建议设备内存 2GB 及以上，可用存储空间 100MB 及以上。

2.2 软件环境

本软件运行于 HarmonyOS NEXT（Stage 应用模型）之上，依赖的系统能力包括：
ArkTS 语言运行时、ArkUI 声明式 UI 框架、@kit.ArkData 本地数据存储能力。
若使用账号与云同步功能，需设备可访问网络，并依赖华为端云一体化服务
（AppGallery Connect）的认证服务与云数据库能力。

2.3 安装与卸载

安装：在应用市场搜索本软件名称，或在应用详情页点击安装；安装完成后，桌面
出现应用图标，图标下方显示应用名称"菲特"。

启动：点击桌面图标即可启动。首次启动时，若尚未登录，进入登录 / 注册页面；
若已处于登录状态，则直接进入主界面。

卸载：在系统设置的应用管理中找到本软件，选择卸载；或在桌面长按应用图标，
拖入卸载区域。卸载会删除设备本机保存的全部数据，建议卸载前先登录并完成一次
云同步，或使用应用内备份功能导出备份包。

三、界面与导航

3.1 启动流程与登录态分流

本软件在冷启动时按登录状态自动分流：

- 未登录：进入登录页；可在登录页切换到注册页完成账号注册。
- 已登录：直接进入主界面，减少重复登录操作。

登录方式包括手机验证码、邮箱密码、华为账号三种。用户也可以选择不登录，
直接使用全部本地功能。

3.2 主界面结构

登录后进入主界面。主界面底部为四个内容标签页，分别是：首页、计划、回顾、我的。

- 首页：呈现今日训练、计划的当前状态、以及常用功能的快捷入口。
- 计划：呈现训练计划相关内容，包括计划组的浏览、预览与启用。
- 回顾：呈现训练复盘相关内容，包括历史训练、趋势统计与个人纪录。
- 我的：呈现用户资料、身体数据、账号与同步、设置等入口。

除四个标签页外，训练预览以全模态方式在当前界面之上叠加呈现，训练执行、
训练完成摘要、动作库与动作详情、身体数据、账号与同步、设置等以独立页面方式
打开，可通过返回操作回到上一级界面。

四、功能操作说明

4.1 训练流程

训练流程由预览、执行、完成摘要三个阶段组成。

（1）进入训练预览。在首页的今日训练入口点击，或在计划页选择某日安排后进入，
界面以全模态方式呈现本次训练的动作清单与组次安排。用户在预览中可确认本次
训练包含的动作及其顺序。

（2）执行训练。在预览页确认后进入训练执行页。执行页按动作顺序呈现当前动作，
用户可以逐组录入该组的次数与重量；组与组之间提供计时辅助，便于控制组间休息
时间；执行过程中可随时查看当前动作的要领提示，以确认动作要点。

（3）查看完成摘要。全部动作完成后进入训练完成页，界面展示本次训练的完成
情况，包括完成的组数与训练用时等汇总信息。完成后本次训练记录即写入本地
数据，可在回顾页查看。

4.2 训练计划

（1）浏览计划组。在计划页或计划组页查看内置的计划组，计划组按每周训练分化
数组织，包含不同的训练日安排。

（2）查看计划组详情。进入计划组详情页可以预览该计划组中各训练日的动作与
组次安排，判断是否符合当前的训练目标与可用时间。

（3）启用计划。在计划组详情页选择启用后，该计划即成为当前计划并保存到本地。
启用后，首页的今日训练入口会按当前计划呈现当日安排。

（4）进入训练。从首页今日训练入口或计划页的当日安排点击，即可进入训练预览，
后续流程与 4.1 所述一致。

4.3 训练复盘

回顾页提供多层次的训练数据视图：

（1）历史训练。以列表形式呈现过往每次训练，点击可查看单次训练的详情，
包括该次训练的动作、组次与重量记录。

（2）周训练趋势。以周为单位汇总训练量变化，用于判断训练频率与训练容量的
走向。

（3）动作个人纪录。按动作维度展示个人最好成绩，并支持下钻查看该动作的历史
变化，用于判断力量是否在提升。

（4）肌肉分布。按肌群维度汇总训练量分布，用于发现训练是否偏科。

（5）进阶洞察。基于上述数据给出训练进展的判断提示，辅助用户决定是否调整
训练强度或计划安排。

4.4 动作库

（1）浏览动作。动作库页以列表形式呈现动作，每条包含动作名称与简要信息。

（2）筛选。支持按条件筛选动作，便于快速定位目标肌群或器械类型的动作。

（3）收藏。可将常用动作加入收藏，便于在后续查阅时快速找到。

（4）查看动作详情。点击某条动作进入动作详情页，页面包含动作要点说明与
动作演示素材；演示素材随安装包内置，查看时从本机读取，不消耗流量。

4.5 身体数据

身体数据页用于记录体重、体脂等身体指标。录入后按时间形成记录序列，可在页面
中查看变化情况。身体数据默认仅保存在设备本机，当前版本不参与云同步。

4.6 账号与云同步

（1）登录。在登录页选择登录方式：手机验证码登录需先获取验证码并填入；
邮箱密码登录需填写邮箱与密码；也可使用华为账号登录。

（2）注册。在注册页填写所需信息完成账号注册；注册成功后即可登录。

（3）云同步。登录后即可使用云同步，无需额外的同步页面。软件会在
登录成功时自动触发一次同步；训练完成后也会在后台静默触发一次。同步动作
本身不需要用户手动干预。

（4）同步范围。同步内容为目标、计划、训练记录与用户资料，以整包快照形式
上传，云端按用户 ID 隔离；身体数据、训练草稿、内容库与媒体缓存不参与同步。

（5）退出登录。退出登录会清除本机的登录状态，本机业务数据保留在设备上，
不会被退出操作删除。云端快照保留，供再次登录时恢复。

（6）离线与降级。未登录或未配置云端凭据时，软件以本地模式运行，全部核心
功能离线可用，不发起网络请求。

4.7 数据备份与恢复

（1）导出备份。使用应用内的备份功能，将本机数据导出为 JSON 格式的备份包，
保存到用户选择的本地位置。备份包由用户自行保管。

（2）导入恢复。在需要恢复的设备上使用导入功能，选择此前导出的备份包，
将数据恢复到本机。

（3）系统备份。软件承接系统级备份回调；若用户在系统设置中开启了云备份，
操作系统可能将应用数据纳入备份并由系统上传至用户自己的云账号。该传输由
系统与用户账号设置控制，软件自身不发起、不干涉。

4.8 设置

设置页提供以下项目：

（1）重量单位：切换显示与录入所使用的重量单位，设置后全局生效。

（2）语言：切换界面语言选项；当前版本界面文案以简体中文呈现。

（3）周开始日：设置一周的起始日，影响复盘中按周汇总的统计口径。

（4）训练提醒、成就提醒、声音与震动、训练中屏幕常亮、匿名使用数据、
健康数据授权等开关：记录用户的开关偏好并持久化保存。

上述设置项均持久化保存于设备本机，应用重启后保持。

4.9 典型使用场景

场景一：首次使用并开始第一次训练

（1）安装完成后点击桌面图标启动本软件。若尚未登录，界面进入登录页；
此时可以不做任何登录操作，直接使用本地功能。

（2）进入主界面后位于首页。首页在尚未启用训练计划时呈现空态引导，
提示用户前往计划页选择训练计划。

（3）切换到计划页，浏览内置的计划组。计划组按每周训练分化数组织，
用户根据自己每周可训练的天数与训练水平选择一个计划组。

（4）进入计划组详情页，预览该计划组中各训练日的动作与组次安排，
确认符合预期后选择启用。

（5）计划启用后回到首页，首页呈现"今日训练"入口，点击即可进入训练预览，
开始第一次训练。

场景二：完成一次完整的训练

（1）在首页点击今日训练入口，界面以全模态方式呈现训练预览，
列出本次训练包含的动作与组次安排。

（2）确认无误后进入训练执行页，按动作顺序逐组完成训练；
每完成一组，录入该组的次数与重量。

（3）组间休息时可利用页面提供的计时辅助控制休息时长；
需要确认动作要点时，可查看当前动作的要领提示。

（4）全部动作完成后进入训练完成页，查看本次训练的汇总信息。

（5）本次训练记录随即写入本机数据，可在回顾页中查看与统计。

场景三：查看训练效果并调整安排

（1）切换到回顾页，首先看到历史训练列表，确认近期训练是否按计划执行。

（2）查看周训练趋势，判断训练频率与训练容量是否稳定。

（3）下钻到具体动作的个人纪录，比较同一动作的历史成绩变化，
判断力量是否在提升。

（4）查看肌肉分布统计，确认训练量在各肌群之间的分配是否均衡。

（5）根据上述判断，决定维持当前计划或回到计划页更换计划组、
调整训练安排。

场景四：更换设备后恢复数据

（1）在原设备上登录账号，登录成功时软件会自动将训练数据上传至云端。

（2）在新设备上安装本软件，使用同一账号登录。

（3）登录成功时，软件会自动触发同步，将云端快照恢复到新设备；
设备上积累的本地变更也会在训练完成后自动同步。

（4）若未使用账号，也可以在原设备上使用备份功能导出 JSON 备份包，
在新设备上通过导入功能恢复数据。

五、数据与隐私

5.1 权限说明

本软件仅申请网络访问与振动两项权限，分别用于账号登录与云同步、训练中的触觉
反馈。软件不申请位置、通讯录、短信、相机、麦克风、相册、日历等敏感权限；
不登录时网络权限不被使用，全部本地功能离线可用。

5.2 数据存储与流向

本地数据写入应用私有沙箱，其他应用无法直接读取。仅在用户登录并开启云同步
后，目标、计划、训练记录与用户资料会以整包快照形式上传至云端，用于跨设备
恢复；云端数据按用户 ID 隔离，权限配置为仅数据创建者读写。

5.3 用户对数据的控制

用户可以随时使用全部本地功能而不登录；登录后也可随时退出登录；
可以清除本机数据或卸载软件以删除设备上的全部本地数据；如需删除云端快照，
可通过隐私政策中列明的联系方式提出申请。

六、常见问题

问题一：为什么不登录也能使用？
本软件为本地存储优先设计，训练记录、计划、复盘等核心功能均在本机完成，
不依赖账号。账号与云同步仅用于跨设备恢复数据。

问题二：换设备后数据如何迁移？
登录同一账号并开启云同步后，在新设备上登录即可从云端恢复；也可以使用
备份导出的 JSON 备份包，在新设备上导入恢复。

问题三：训练记录会丢失吗？
本地数据保存在应用私有沙箱内，正常情况下不会丢失。但清除应用数据、卸载
应用或更换设备时会丢失本机数据，建议定期同步或导出备份。

问题四：动作演示素材需要联网吗？
不需要。动作演示素材随安装包内置，查看时从本机读取。

附录：术语说明

1RM：单次最大力量（One Repetition Maximum），指某动作只能完成一次的
最大重量，本软件按 Epley 公式由实际完成的组次与重量估算。

PR：Personal Record，个人纪录，指某动作在历史记录中的最好成绩。

分化训练：将每周训练日按肌群或动作类型划分的训练组织方式，如三分化、
四分化、五分化。

组 / 次：训练的基本计量单位，"一组"指连续完成若干次动作，"次数"指
一组内完成的动作个数。

快照：将一组数据整体序列化后的完整副本；本软件的云同步以整包快照为单位
上传与恢复。

云端快照恢复：登录成功后，软件比对本地数据与云端快照的版本，按最近写入
为准决定上行或下行，用于更换设备后的数据恢复。

离线模式：未登录或未配置云端凭据时软件的工作模式；此时全部核心功能在本机
完成，不发起网络请求。

本地演示模式：未配置云端凭据时，账号相关界面以演示数据呈现并明示，不对
外发起真实网络请求。
