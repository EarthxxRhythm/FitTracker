## 11. 软件的主要功能（0/100-1300）

```
本软件是一款运行于 HarmonyOS 的健身训练记录应用，围绕“记录—复盘—调整”的训练闭环设计，主要功能如下：

1. 启动与登录态分流。应用启动时按登录状态自动分流：未登录进入登录页，可在登录页切换到注册页；已登录直接进入主界面，减少每次打开的操作步骤。

2. 训练流程。提供训练预览 → 训练执行 → 完成页的完整链路。训练执行页支持逐组录入次数与重量，并可查看当前动作的要领提示；训练完成后进入完成页，展示本次训练的完成反馈与训练连续记录。

3. 训练计划。内置 4 套按分化数成套的预置计划（二分化（上下肢）、三分化、四分化、五分化），用户可浏览计划组详情、预览各训练日的动作与组次安排并一键启用；启用后首页直接呈现“今日训练”入口，点击即可进入训练预览。

4. 训练复盘。提供历史训练列表与单次训练详情、周训练趋势、动作个人纪录（PR）下钻、肌肉分布统计与进阶洞察，帮助用户从数据层面判断训练是否在进步。

5. 动作库。内置动作列表与详情，支持按部位/肌群两级筛选、按器械筛选与收藏常用动作；动作详情包含目标肌群、器械要求、动作要点说明与内置的动作演示素材，素材随安装包内置，运行时不联网下载。

6. 身体数据。支持记录体重、体脂等身体数据，形成随时间的变化记录，用于与训练数据相互印证。

7. 账号与云同步（可选）。支持手机验证码、邮箱密码、华为账号三种登录方式；登录成功后自动触发云同步，将目标、计划、训练记录、用户资料以整包快照形式上传至华为端云一体化服务（AGC）云数据库，用于跨设备恢复，云端数据按用户 ID 隔离。未配置云端凭据时自动进入本地演示模式，不发起网络请求。

8. 数据备份与恢复。支持将本地数据导出为 JSON 备份包，并可导入恢复；同时承接系统备份回调。

9. 设置。提供体重单位、语言、周开始日等常规项，以及训练提醒、成就提醒、声音与震动、训练中屏幕常亮等开关；并含隐私说明与退出登录入口。设置项持久化保存，应用重启后保持。

10. 权限最小化。应用仅申请网络访问与振动两项权限（分别用于账号登录与云同步、训练中的触觉反馈），不申请位置、通讯录、相机、麦克风等敏感权限；不登录时全部本地功能均可离线使用。
```

（实测约 900 字符，在上限内。）

## 材料生成（可复现）

材料由脚本从仓库直接生成，产出落在 `test_run\copyright\`（该目录被 gitignore，材料不入库）：

```bash
cd apps/harmony
node tools/make-copyright-source.mjs   # 源程序 txt：连续前 30 页 + 后 30 页，每页 50 行
node tools/make-copyright-doc.mjs      # 说明书 txt：按每页 30-40 行均匀分页
node tools/make-copyright-pdf.mjs      # 两份 txt → 同名 PDF（上传用）
```

产出文件：

| 文件 | 用途 |
| --- | --- |
| `源程序（菲特健身训练软件V1.0）.pdf` | **上传用**（60 页，每页 50 行） |
| `说明书（菲特健身训练软件V1.0）.pdf` | **上传用**（10 页，每页 37 行） |
| `源程序（…）_合计60页.txt` | PDF 的输入源；若系统只接受 txt 则传这份 |
| `源程序（…）_前30页.txt` / `_后30页.txt` | 若系统要求分开上传 |
| `说明书（…）.txt` | PDF 的输入源 |

### PDF 是怎么生成的

用本机 Chrome 无头模式打印，**不是**把 txt 直接改名。原因：官方硬性要求是**每页行数**（源程序 ≥50 行、文档 ≥30 行），若让渲染器自行分页，长行折行会多挤出一页，导致「第 N 页」与实际物理页错位。脚本因此：

1. 按 txt 的页边界切成 section，显式插入分页符；
2. **实测产出 PDF 的物理页数**（解压对象流数 `/Type /Page`），与逻辑页数不符就缩 0.5pt 重排——源程序从 11pt 起步，收敛到 **9.5pt**（88→63→61→60 页）；
3. 校验字体已嵌入（未嵌入时中文在审核方电脑上会变方框）。

`make-copyright-pdf.test.mjs` 把上述不变量钉在测试里（解析不丢行、页数守恒、字体嵌入）。

脚本内置敏感内容哨兵（API key / 私钥 / 硬编码口令等），命中即打印可疑行并以非零码退出——避免把密钥随材料交出去。2026-10-16 实测：**未命中**。
