## 9. 开发目的（0/500）

```
为健身训练人群提供一款本地优先、隐私友好的训练记录与复盘工具。以「组数 × 次数 × 重量」的结构化录入替代纸质或备忘录式的零散记录，并按 Epley 公式自动估算 1RM 以量化力量变化；再以历史训练、周趋势、动作个人纪录、肌肉分布等复盘视图，帮助训练者判断当前计划是否有效、强度何时需要调整。数据默认仅保存在设备本机，不强制注册账号；用户可选择登录账号做跨设备恢复。
```

## 11. 软件的主要功能（0/100-1300）

```
本软件是一款运行于 HarmonyOS 的健身训练记录应用，围绕“记录—复盘—调整”的训练闭环设计，主要功能如下：

1. 启动与登录态分流。应用启动时按登录状态自动分流：未登录进入登录/注册页，已登录直接进入主界面，减少每次打开的操作步骤。

2. 训练流程。提供训练预览 → 训练执行 → 完成摘要的完整链路。训练执行页支持逐组录入次数与重量、组间计时，并可查看当前动作的要领提示；训练完成后生成摘要，展示本次训练的总容量、组数与用时。

3. 训练计划。内置按分化数成套的预置计划组（如二分化、三分化、四分化、五分化），用户可浏览计划详情、预览每日安排并一键启用；启用后首页直接呈现“今日训练”，点击即可进入训练预览。

4. 训练复盘。提供历史训练列表与详情、周训练趋势、动作个人纪录（PR）下钻、肌肉分布统计与进阶洞察，帮助用户从数据层面判断训练是否在进步。

5. 动作库。内置动作列表与详情，支持按肌群、器械筛选和收藏常用动作；动作详情包含动作要点说明与内置的动作演示素材，素材随安装包内置，运行时不联网下载。

6. 身体数据。支持记录体重、体脂等身体数据，形成随时间的变化记录，用于与训练数据相互印证。

7. 账号与云同步（可选）。支持手机验证码、邮箱密码、华为账号三种登录方式；登录后可开启云同步，将目标、计划、训练记录、用户资料以整包快照形式上传至华为端云一体化服务（AGC）云数据库，用于跨设备恢复，云端数据按用户 ID 隔离。未配置云端凭据时自动进入本地演示模式，不发起网络请求。

8. 数据备份与恢复。支持将本地数据导出为 JSON 备份包，并可导入恢复；同时承接系统备份回调。

9. 设置。提供重量单位、语言、周开始日，以及训练数据同步、训练中屏幕常亮等开关项；设置项持久化保存，应用重启后保持。

10. 权限最小化。应用仅申请网络访问权限（用于账号登录与云同步），不申请位置、通讯录、相机、麦克风等敏感权限；不登录时全部本地功能均可离线使用。
```

## 材料生成（可复现）

两份材料由脚本从仓库直接生成，产出落在 `test_run\copyright\`（该目录被 gitignore，材料不入库）：

```bash
cd apps/harmony
node tools/make-copyright-source.mjs   # 源程序：连续前 30 页 + 后 30 页，每页 50 行
node tools/make-copyright-doc.mjs      # 说明书：按每页 30-40 行均匀分页
```

产出四个文件：

| 文件 | 用途 |
| --- | --- |
| `源程序（菲特健身训练软件V1.0）_合计60页.txt` | 上传用（前 30 + 后 30 合并） |
| `源程序（菲特健身训练软件V1.0）_前30页.txt` | 若系统要求分开上传 |
| `源程序（菲特健身训练软件V1.0）_后30页.txt` | 同上 |
| `说明书（菲特健身训练软件V1.0）.txt` | 文档鉴别材料 |

脚本内置敏感内容哨兵（API key / 私钥 / 硬编码口令等），命中即打印可疑行并非零退出——避免把密钥随材料交出去。当前实测结果：**未命中**。
