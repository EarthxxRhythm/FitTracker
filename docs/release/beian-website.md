### 1.2 你必须自己核（我无腾讯云控制台访问权）

这四条任一不满足会被初审直接拦下，口径来自腾讯云《备案云资源》：

| # | 要求 | 核对位置 |
| --- | --- | --- |
| 1 | **地区**：中国境内（IP 已是境内，需确认实例地域） | 轻量应用服务器详情页 |
| 2 | **计费模式**：包年包月（按量付费不行） | 实例详情 / 计费项 |
| 3 | **购买时长**：包月 ≥3 个月，且**备案期间剩余有效期 ≥1 个月** | 实例到期时间 |
| 4 | **网络**：绑定境内公网 IP 且**带宽不为 0**；**不支持绑定 EIP 备案** | 实例网络配置 |

### 1.3 域名侧前置（最容易卡住的一步）

- 域名必须**已完成实名认证**，且实名主体（姓名 / 证件类型 / 证件号码）**与备案主体逐项一致**。
- 阿里云实名审核一般 1–7 个工作日；**实名信息同步到工信部约需 3 天**，建议等满 3 天再提交备案，否则管局核验不到实名信息会直接驳回。
- 域名需在有效期内。

### 3.3 网站服务名称命名说明（个人主体最易驳回的一项）

腾讯云《网站命名建议》硬约束，逐条对照：

| 规则 | 对「菲特」的影响 |
| --- | --- |
| 三个字以上 | `菲特` 只有 2 字 → **不合格** |
| 不能是纯英文 / 纯数字 | `FitTracker` → **不合格** |
| 个人备案不能以域名、姓名命名 | 不能用 `earthrhythm`、不用人名 |
| 不能含公司/组织/地名/成语 | 「菲特」不含，可用 |
| 不能含经营性词汇（购买、交易、优惠券、电子商务） | 需规避 |
| 必须体现网站内容 | 需含「健身」「训练」类词 |

→ 推荐：**`菲特健身训练记录`**（8 字，含产品名 + 内容词，无违规元素）。

备选（若管局要求更贴近个人性质）：`菲特训练记录分享`、`菲特健身记录工具`。

不要用「菲特官网」——个人主体用「官网」易被判为经营性/企业性质。

## 4. 网站侧准备

### 4.1 备案号展示（通过后必做，法规强制）

拿到备案号后：

1. 改 `web/src/App.tsx:407` —— 把 `<span className="pending" data-pending="icp">ICP 备案号待取得</span>` 换成真实备案号，并按规范链接到 `https://beian.miit.gov.cn/`。
2. 样式复用 `web/src/legacy.css:421` 已调好的 `.pending` 对比度（5.44:1，达 WCAG AA），换号后不要退回低对比度写法。
3. `npm run build` → 同步 `web/dist/` 到服务器 `/opt/fittracker/web/` → `docker restart fittracker-caddy`（**必须 restart，不能 reload**，见 `server/deploy/Caddyfile` 顶部注释）。

### 4.2 备案期间网站状态（风险项，需先决策）

腾讯云《首次备案》原文：「如果您的网站/域名……**从未办理过备案，在开通服务前，需在腾讯云备案系统进行首次备案的操作**。」

当前 `https://earthrhythm.cloud/` 已在 443 对外提供服务，而备案尚未提交。两条路：

| 方案 | 做法 | 代价 |
| --- | --- | --- |
| **A（推荐）** | 备案提交前把官网块暂时摘除（Caddyfile 官网块停用或加 IP 白名单），通过后恢复 | 官网短暂不可访问；`api` 块不受影响 |
| B | 保持在线直接提交 | 管局核验发现已开通服务，有驳回或云厂商阻断风险 |

摘除只影响 `earthrhythm.cloud, www.earthrhythm.cloud` 这一块，Supabase API 走独立块，不受影响。

### 4.3 内容一致性

管局审核期间可能访问站点核验，页面内容需与备案填写的「服务内容」相符。当前首页为产品介绍 + 截图，法务页可访问，与「健身训练记录工具」一致。

## 5. 通过后：公安联网备案（网站业务）

`gongan-beian-form.md` 覆盖的是**公安备案的 APP 业务**，网站业务是独立入口：

- 平台：全国互联网安全管理服务平台 `beian.mps.gov.cn` → 业务办理 → **网站业务** → 新增网站
- 时限：取得 ICP 备案号后 **30 日内**
- 材料：ICP 备案号、域名、服务器 IP、主体证件、网站负责人信息
- 下号后同样需在网站底部展示公安备案号

## 7. 与 APP 备案的关系

| | ICP 网站备案（本文） | ICP APP 备案（`beian-materials.md`） |
| --- | --- | --- |
| 指向 | 域名 + 服务器 | APP 包名 + 公钥指纹 |
| 主体材料 | 身份证、域名、服务器 | 应用名称、包名、公钥、MD5 指纹 |
| 结果 | 网站备案号，展示在网页底部 | APP 备案号，回填应用市场提审 |

两者可以同一订单提交（腾讯云支持一个订单同时备案网站与 APP，个人主体各限 1 个），互不冲突。
