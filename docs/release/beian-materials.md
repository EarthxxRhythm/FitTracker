## 3. 复现方式（换证书或换机器时重跑）

```bash
CERT="$HOME/.ohos/release-keys/fittracker_release.cer"
# 证书链共 3 张，取最后一张（Leaf）
python -c "
import re
s = open(r'C:/Users/19308/.ohos/release-keys/fittracker_release.cer', encoding='utf-8').read()
certs = re.findall(r'-----BEGIN CERTIFICATE-----.*?-----END CERTIFICATE-----', s, re.S)
open(r'C:/Users/19308/.ohos/release-keys/leaf.pem','w').write(certs[-1])
print('leaf written, chain len =', len(certs))
"
L="$HOME/.ohos/release-keys/leaf.pem"
openssl x509 -in "$L" -noout -fingerprint -md5      # MD5 指纹
openssl x509 -in "$L" -noout -fingerprint -sha256   # SHA256 指纹
openssl x509 -in "$L" -noout -subject -dates        # 主体与有效期
openssl x509 -in "$L" -pubkey -noout                # 公钥
```

⚠️ **必须取 Leaf**：`~/.ohos/config/*.cer` 与 `release-keys/*.cer` 都是**多级证书链**。取到 Root CA 或中间 CA 的指纹是不通用的（此前调试证书指纹注册曾踩过这个坑）。

## 4. 备案流程（[用户] 执行，Agent 无法代办）

备案是**账号级外部操作**（需要你的实名主体、接入商账号、服务器/云资源），项目计划中已明确划归用户侧。

1. **确认主体**：个人 or 企业 —— 影响可备案的 APP 类别与所需证件；
2. **选接入商**：可用**华为云**（与现有 AGC 生态一致）；
3. **备齐资源**：备案通常需要**备案服务码**（购买指定云服务器/云资源后领取）；
4. **提交材料**：
   - 主体证件（个人身份证 / 企业营业执照）
   - APP 信息：应用名称、包名、**公钥 + MD5 指纹**（本文档 §1/§2 直接抄）
   - 涉及云资源的还需云服务信息
5. **审核链路**：接入商初审 → 工信部审核（官方口径 **20 个工作日内**）→ 下发**备案号**；
6. **回填**：拿到备案号后，填入 AGC 提审信息。

## 5. 注意事项

- **这是上架最长的一段周期**（计划文档估 **1–2 周+**），越早启动越好，可与工程侧并行；
- **所有 APP 必须备案**；**端云一体化（本项目使用 AGC 认证 + 云数据库）必须 ICP 备案**——这是提审前置；
- 发布证书**有效期 3 年（至 2029-10-09）**：证书到期换证后，备案里的公钥与指纹需同步更新（备案信息与实际证书不一致可能导致问题）；
- 若后续更换 `bundleName`，备案信息也需一并变更。

## 6. 详细操作步骤（首次备案照此走）

> 流程部分来自工信部备案通用口径 + 本地官方文档库取证；**具体界面按钮位置以华为云实际页面为准**（华为云文档站是 SPA，抓取只能拿到导航壳，拿不到步骤页正文）。

### 6.1 前置认知：三条硬约束（均已取证）

**① 必须由接入商代办，不能自己直接找工信部**

> 官方 FAQ（`faqs-appgallery-13`）：「HarmonyOS应用/元服务备案要求与APP备案一致，**均由接入商代为备案**。」

**② 端云一体化「没有备案码」，必须自购服务器** ← **本项目最特殊的一条**

> 官方 FAQ（`faqs-cloudfoundation-2`）原文：「端云一体化**没有备案码**，因此**需要准备一个服务器**，用于存放诸如隐私或用户协议，端云一体化是技术方案，不是备案的方案。」「使用端云一体化开发中的云数据库的 App **不属于单机应用，必须进行 ICP 备案**。」

**实操含义**：菲特 曾规划使用 AGC 云数据库；**2026-10-28 已改定为自托管 Supabase**（腾讯云 Lighthouse `106.55.37.80`，自托管 Supabase），因此备案不需要再为「端云一体化」单独购机，直接用这台服务器 + 自有域名走 ICP 流程即可。

**③ 工具类无需前置许可**

> 官方 FAQ（`faqs-appgallery-95`）：「APP仅提供普通工具、信息展示、企业官网配套等无专项许可要求的服务，**无需前置许可**。」

菲特 属健身记录工具 → 备案表单里「**相关前置许可**」选「**否**」。

### 6.5 阶段 3：华为云初审 + 实名核验（1–3 个工作日）

- 华为云审核材料，**可能电话核实**（保持手机畅通）；
- 可能要求**实名核验**：人脸识别或幕布拍照（以华为云提示为准）。

### 6.6 阶段 4：工信部 / 管局审核（20 个工作日内）

- 材料提交至各省通信管理局；
- ⚠️ **短信核验**：工信部会向备案手机号发短信，**必须按提示回复验证**——漏回会被退回重来，这是最常见的卡点；
- 期间可能有管局电话核实。

### 6.7 阶段 5：下号并回填

1. 获得**备案号**（形如 `XICP备XXXXXXXX号-XXA`）；
2. **回填 AGC**：应用上架 → 版本信息 → 备案号字段；
3. 回填后告知，同步更新本文档与 `release-build-runbook.md` 提审清单。

## 7. 腾讯云路径（本次确定的接入商）

> 依据：腾讯云官方文档《[备案云资源](https://cloud.tencent.com/document/product/243/18908)》《[准备 ICP 备案域名](https://cloud.tencent.com/document/product/243/35819)》（2026-10-09 抓取）。

### 7.1 先核对：你的服务器满足备案条件吗（4 条硬性，须同时满足）

据《备案云资源》，**云服务器（CVM）或轻量应用服务器（Lighthouse）**需同时满足：

| 要求 | 说明 |
| --- | --- |
| **地区** | **中国境内**。⚠️ **中国香港及境外地区「无需进行备案，也不能用于备案」** |
| **计费模式** | **仅支持包年包月**（按量付费不行） |
| **购买时长** | **包月 ≥3 个月**（含续费），且**备案期间剩余有效期 ≥1 个月** |
| **网络** | 绑定**中国境内公网 IP**，且**带宽不能为 0**；**不支持绑定 EIP 进行备案** |

补充：**个人账号**同一实例最多备案 **5 个**网站/APP（企业账号 10 个）。

> **若有一条不满足，先调整**：按量付费转包年包月、续费到 3 个月以上、确认地域是中国境内。这四项不满足会直接被初审拦下。

### 7.2 ⚠️ APP 备案要填「域名」（本项目的关键注意点）

腾讯云《准备 ICP 备案域名》原文：

> 「进行 APP 应用服务 ICP 备案时，**APP 所在的运行平台使用的域名**进行填写。域名实名信息需要与备案主体一致，同时支持最多四级域名填写……可以输入多个域名。」

**对 菲特 的含义（2026-10-28 更新）**：应用后端已改为自托管 Supabase（`106.55.37.80`），域名不再属于华为，**需要自备一个已完成实名认证的域名**指向该服务器。因此需要确认：

- 腾讯云 APP 备案表单里**域名是否必填**；
- **若必填**：需要注册一个自己的域名（做**实名认证**，且**实名主体须与备案主体一致**），该域名指向你的腾讯云服务器。另外腾讯云文档明确提示：**域名实名认证后约需 3 天信息才同步到工信部，建议等满 3 天再提交备案**，否则可能因核验不到实名信息而失败。

**标注**：此段是从文档措辞推断的最可能情形，**具体以备案表单实际必填项为准**。

### 7.3 服务器还能一举两得

官方 FAQ 说这台服务器是用来「存放诸如隐私或用户协议」的。建议：

- 在腾讯云服务器上把 `docs/legal/privacy-policy.md` 与 `docs/legal/user-agreement.md` **部署成静态页面**；
