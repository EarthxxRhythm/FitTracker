# 菲特 软件著作权登记（软著）指南

> 建立：2026-10-11。用途：国内应用市场（含华为应用市场）提审时通常要求提供软著登记证书。本文件收录官方口径、本项目实测参数与材料准备方式。
> 配套：`docs/release/beian-materials.md`（APP 备案取证）、`docs/release/release-build-runbook.md` §12（上架材料待办）。

## 1. 结论先行

- **官方渠道免费**：软件著作权登记无登记费（国家层面已停征），自己办不花钱。
- **代办是服务费**：市面 400–1000 元（半包仅代提交 / 全包代写材料），材料责任仍在你这边；材料不合规被退，代办也救不了。
- **法定审查期 60 日**：依据《计算机软件著作权登记办法》第二十条——「中国版权保护中心应当自受理日起 60 日内审查完成」。实际多为 1–2 个月，**被退回补正要重新排队**。
- **入口**：中国版权保护中心 <https://www.ccopyright.com.cn/> → 版权登记 → 软件登记（<https://register.ccopyright.com.cn/registration.html#/registerSoft>）。
- ⚠️ **软著比备案慢**：备案 1–3 周，软著 1–2 月。若目标市场要求软著，**它是上架链上的关键路径，应最先启动**。

## 2. 材料四要素

| 材料 | 要求 |
| --- | --- |
| 申请表 | 线上填写：软件全称、简称、版本号、开发完成日期、首次发表日期、著作权人 |
| **源程序** | **前 30 页 + 后 30 页，每页 50 行**（共 60 页）；程序总行数不足 3000 行时全部提交 |
| **说明书** | 同样适用 60 页规则；图文并茂地说明软件功能、模块与操作流程 |
| 身份证明 | 个人：身份证；企业/个体：营业执照 |

## 3. 本项目实测参数

- `entry/src/main/ets`：**97 个 `.ets` 文件、28,588 行**（剔除空行与纯注释后 25,508 行）——远超 3000 行门槛。
- 因此源程序须按「前 1500 行 + 后 1500 行」截取，共 60 页（每页 50 行）。
- **提交前必须排除的内容**（出现即可能被质疑或泄露）：
  - 签名材料类：`build-profile.json5` 中的 `signingConfigs` 本机路径与口令密文；
  - 任何凭据文件：`agconnect-services.json`、`local.properties`、Supabase 的 URL/Key；
  - 第三方库源码（`oh_modules/`）—— 只提交自有代码。

## 4. 命名一致性（最容易踩的坑）

应用市场会核验软著名称与上架名称是否一致（或明显关联），不一致会被要求补交证明材料。**先定名，再提交软著**——软著改名要走变更登记，很慢。

当前名称链路：

| 位置 | 值 | 落点 |
| --- | --- | --- |
| 应用市场名称 | 菲特 | `AppScope/resources/base/element/string.json`、`entry/.../en_US` 为 FitTracker |
| 法务文本 | 菲特（FitTracker） | `docs/legal/*.md`、`rawfile/legal/*.txt` |

建议软著**软件全称**：`菲特健身训练软件`（含「菲特」且与健身训练功能对应），版本号取 `V1.0`。

## 5. 两个待核实的点（以官方/市场实际要求为准）

1. **是否必须软著**：多个来源称鸿蒙应用上架需提供软著登记证书或电子版权认证，**但本文件未取到官方原文**。请以 AGC 提审页面的实际必填项为准——若不需要，可省 1–2 个月。
2. **提交形式**：线上提交电子材料是否已完全替代纸质邮寄，请按登记系统当期提示操作。
