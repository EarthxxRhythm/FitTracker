# FitTracker 设计系统代码规范文档

> 面向鸿蒙应用开发（ArkUI），适用于 Next 体系。本文档基于 FitTracker 设计原型提取设计特征，将视觉语言转化为可复用的代码规范。凡原型未明确处，均以 `{{占位符}}` 标注，请设计师补充确切数值。

## 1. 设计 Token（Design Tokens）

### 1.1 颜色变量（Color）

全局颜色基于语义与用途分级，统一使用 HSL 或 HEX 定义。所有颜色以 CSS 变量形式注入，禁止在组件内硬编码色值。

css

```
:root {
  /* 品牌主色 */
  --color-primary:         {{占位符：主色，例如 #00C853}};
  --color-primary-hover:   {{占位符：主色悬停态}};
  --color-primary-pressed: {{占位符：主色按压态}};
  --color-primary-disabled:{{占位符：主色禁用态}};

  /* 中性色 */
  --color-neutral-0:   #FFFFFF;
  --color-neutral-50:  {{占位符：浅灰背景}};
  --color-neutral-100: {{占位符：分割线/描边}};
  --color-neutral-200: {{占位符：禁用文字/占位符}};
  --color-neutral-300: {{占位符：辅助文字}};
  --color-neutral-400: {{占位符：正文文字}};
  --color-neutral-500: #000000;

  /* 语义色 */
  --color-success:       {{占位符：如 #4CAF50}};
  --color-warning:       {{占位符：如 #FF9800}};
  --color-error:         {{占位符：如 #F44336}};
  --color-new-record:    {{占位符：新纪录高亮色，推测为金色 #FFD700}};

  /* 背景与表面 */
  --color-surface-primary:   var(--color-neutral-0);
  --color-surface-secondary: var(--color-neutral-50);
  --color-surface-elevated:  {{占位符：卡片投影背景}};

  /* 文字色 */
  --color-text-primary:    var(--color-neutral-500);
  --color-text-secondary:  var(--color-neutral-300);
  --color-text-disabled:   var(--color-neutral-200);
  --color-text-on-primary: #FFFFFF;
}
```

- **规则**：组件引用颜色必须使用 token，不允许私自使用 `#333` 等硬编码。
- **暗黑模式**：后续扩展 `[data-theme="dark"]` 选择器覆盖变量。

### 1.2 字体（Typography）

字体栈优先系统默认，鸿蒙设备使用 HarmonyOS Sans。字号遵循 4px 递进，行高为字号的 1.2–1.5 倍。

| Token | 字号 | 行高 | 字重 | 用途 |
| --- | --- | --- | --- | --- |
| Token | 字号 | 行高 | 字重 | 用途 |
| `--font-display` | 28sp | 36vp | 700 | 大标题（如“开启你的训练之旅”） |
| `--font-headline` | 20sp | 28vp | 600 | 页面标题（如“动作库”、“训练统计”） |
| `--font-title` | 18sp | 24vp | 600 | 卡片标题、对话框标题 |
| `--font-body` | 16sp | 22vp | 400 | 正文、列表项、输入框文字 |
| `--font-body-bold` | 16sp | 22vp | 600 | 强调数据（如“5400kg”） |
| `--font-caption` | 14sp | 18vp | 400 | 辅助说明（如“本周概况”） |
| `--font-small` | 12sp | 16vp | 400 | 标签、时间戳 |
| `--font-timer` | 32sp | 40vp | 700 | 训练计时器（00:12:35） |

css

```
:root {
  --font-family-base: 'HarmonyOS Sans', 'Roboto', sans-serif;
  --font-family-mono: 'HarmonyOS Sans Mono', 'Courier New', monospace; /* 用于数字、计时器 */
}
```

- **规则**：所有文字样式必须引用上述 token，组件内可使用 `font()` 函数（ArkUI）加载；禁止覆盖 `font-family`。

### 1.3 间距（Spacing）

基于 4px 栅格体系，统一使用 8px 基准单位。内外边距均使用 `vp` 单位（虚拟像素）。

| Token | 值（vp） | 用途 |
| --- | --- | --- |
| Token | 值（vp） | 用途 |
| `--space-xs` | 4 | 图标与文字紧贴间距 |
| `--space-sm` | 8 | 列表项内部元素间距 |
| `--space-md` | 16 | 标准内边距、卡片内边距 |
| `--space-lg` | 24 | 组件间纵向间距 |
| `--space-xl` | 32 | 页面区块间距 |
| `--space-2xl` | 48 | 大容器间的留白 |
| `--space-3xl` | 64 | 页面级上下留白 |

**示例**

css

```
.card {
  padding: var(--space-md) var(--space-lg);
  margin-bottom: var(--space-lg);
}
```

### 1.4 圆角（Border Radius）

| Token | 值（vp） | 用途 |
| --- | --- | --- |
| Token | 值（vp） | 用途 |
| `--radius-sm` | 8 | 按钮、输入框、标签 |
| `--radius-md` | 12 | 卡片、面板 |
| `--radius-lg` | 16 | 弹窗、底部动作条 |
| `--radius-full` | 9999 | 药丸形按钮、头像 |

**规则**：除圆形元素外，所有组件圆角必须使用上述 token。

### 1.5 阴影（Shadow）

css

```
:root {
  --shadow-sm: 0 1vp 3vp 0 rgba(0,0,0,0.1);
  --shadow-md: 0 4vp 8vp 0 rgba(0,0,0,0.08);
  --shadow-lg: 0 8vp 24vp 0 rgba(0,0,0,0.12);
}
```

- 卡片（如训练统计面板）使用 `--shadow-sm` 或 `--shadow-md`；浮层/弹窗使用 `--shadow-lg`。

### 1.6 动效（Motion）

| Token | 值 | 用途 |
| --- | --- | --- |
| Token | 值 | 用途 |
| `--duration-fast` | 150ms | 按钮点击反馈 |
| `--duration-base` | 250ms | 页面转场、元素显隐 |
| `--duration-slow` | 400ms | 复杂动画（图表加载） |
| `--ease-in-out` | cubic\-bezier(0.4, 0, 0.2, 1) | 标准缓动 |
| `--ease-out` | cubic\-bezier(0.0, 0, 0.2, 1) | 入场动画 |

**规则**：必须使用 `animateTo()`（ArkUI）并引用以上曲线与时长；禁用 `linear` 动画。

## 2. 组件代码规范（Component Guidelines）

组件以 ArkUI 声明式语法呈现，每个组件封装为独立 `.ets` 文件。以下以原型中的组件示例。

### 2.1 Button（按钮）

来自登录页“登录/注册”按钮、训练页“开始训练”主按钮。

- **变体（Variants）**： - `type: 'primary' | 'secondary' | 'ghost'` - `size: 'large' | 'medium' | 'small'` - `state: 'default' | 'loading' | 'disabled'` - `block: boolean`（是否撑满容器宽度）
- **支持的 props**： typescript ``` interface ButtonProps { text: string; type?: 'primary' | 'secondary' | 'ghost'; size?: 'large' | 'medium' | 'small'; disabled?: boolean; loading?: boolean; block?: boolean; onClick: () => void; } ```
- **禁止覆盖规则**： - 禁止修改主按钮背景色（只能使用 `--color-primary` token）。 - 禁止给 `ghost` 按钮增加投影。 - 最小触摸热区：`48vp x 48vp`。

**代码示例（ArkUI）**

typescript

```
@Component
export struct AppButton {
  @Prop text: string = '';
  @Prop type: 'primary' | 'secondary' | 'ghost' = 'primary';
  @Prop size: 'large' | 'medium' | 'small' = 'medium';
  @Prop disabled: boolean = false;
  @Prop loading: boolean = false;
  @Prop block: boolean = false;
  onButtonClick?: () => void;

  build() {
    Button({ type: this.type === 'ghost' ? ButtonType.Normal : ButtonType.Capsule }) {
      if (this.loading) {
        LoadingProgress().width(20).height(20).color(Color.White)
      } else {
        Text(this.text)
          .fontSize(this.size === 'large' ? 18 : this.size === 'medium' ? 16 : 14)
          .fontColor(this.type === 'primary' ? Color.White : 'var(--color-primary)')
      }
    }
    .width(this.block ? '100%' : 'auto')
    .height(this.size === 'small' ? 36 : 48)
    .backgroundColor(this.type === 'primary' ? 'var(--color-primary)' : Color.Transparent)
    .border({ width: this.type === 'ghost' ? 1 : 0, color: 'var(--color-primary)' })
    .borderRadius('var(--radius-full)')
    .enabled(!this.disabled && !this.loading)
    .onClick(() => this.onButtonClick?.())
  }
}
```

### 2.2 Input（输入框）

来自登录页手机号输入、验证码输入。

- **变体**： - `type: 'text' | 'number' | 'password'` - `prefix`（例如“+86”前缀） - `withClear: boolean` - `state: 'default' | 'error' | 'success'`
- **Props**： typescript ``` interface AppInputProps { value: string; placeholder: string; type?: 'text' | 'number' | 'password'; prefix?: string; errorMessage?: string; maxLength?: number; onChange: (value: string) => void; } ```
- **禁止覆盖规则**： - 禁止修改聚焦边框颜色（必须使用 `--color-primary`）。 - 错误状态仅允许 `--color-error`。 - 高度必须为 `48vp`（除非特殊指定）。

**代码示例**

typescript

```
@Component
export struct AppInput {
  @Link value: string;
  @Prop placeholder: string = '';
  @Prop type: 'text' | 'number' | 'password' = 'text';
  @Prop prefix?: string;
  @State focused: boolean = false;

  build() {
    Row() {
      if (this.prefix) {
        Text(this.prefix)
          .fontSize('var(--font-body)')
          .fontColor('var(--color-text-primary)')
          .margin({ right: 'var(--space-xs)' })
      }
      TextInput({ text: $$this.value, placeholder: this.placeholder })
        .type(this.type === 'number' ? InputType.Number : InputType.Normal)
        .fontSize('var(--font-body)')
        .borderRadius('var(--radius-sm)')
        .backgroundColor('var(--color-surface-secondary)')
        .border({ width: 1, color: this.focused ? 'var(--color-primary)' : 'var(--color-neutral-100)' })
        .height(48)
        .layoutWeight(1)
        .onFocus(() => this.focused = true)
        .onBlur(() => this.focused = false)
    }
    .width('100%')
    .padding({ left: 'var(--space-md)', right: 'var(--space-md)' })
  }
}
```

### 2.3 Card（卡片）

用于“训练统计”页面的周统计、力量趋势，以及“今日动作”列表。

- **变体**： - `variant: 'elevated' | 'outlined'` - `padding: 'default' | 'compact'`
- **Props**： typescript ``` @Component export struct AppCard { @Prop variant: 'elevated' | 'outlined' = 'elevated'; @Prop padding: 'default' | 'compact' = 'default'; @BuilderParam content: () => void; } ```
- **禁止覆盖规则**： - 投影必须来自 token，禁止使用 `boxShadow: 10px 10px` 等自定义。 - 标题必须使用 `--font-title` token。 - 圆角只能使用 `--radius-md`。

**代码示例**

typescript

```
@Component
export struct AppCard {
  @Prop variant: 'elevated' | 'outlined' = 'elevated';
  @Prop padding: 'default' | 'compact' = 'default';

  build() {
    Column() {
      this.content()
    }
    .width('100%')
    .padding(padding === 'default' ? 'var(--space-md)' : 'var(--space-sm)')
    .backgroundColor('var(--color-surface-primary)')
    .borderRadius('var(--radius-md)')
    .shadow(variant === 'elevated' ? 'var(--shadow-md)' : '')
    .border(variant === 'outlined' ? { width: 1, color: 'var(--color-neutral-100)' } : {})
  }
}
```

### 2.4 Tab/TabBar（底部导航栏）

原型底部：“训练、动作库、统计、我的”四个 tab。

- **变体**： - `tabs: Array<{key: string, icon: Resource, label: string}>` - `activeKey: string`
- **Props**： typescript ``` interface TabBarItem { key: string; icon: Resource; activeIcon?: Resource; label: string; } ```
- **禁止覆盖规则**： - 字号固定为 `12sp`（`--font-small`）。 - 激活颜色固定 `--color-primary`，非激活固定 `--color-neutral-300`。 - 栏高度固定 `56vp`，图标大小 `24vp`。

**代码示例**

typescript

```
@Component
export struct MainTabBar {
  @Link currentTab: string;
  @State tabs: TabBarItem[] = [
    { key: 'training', icon: $r('app.media.ic_train'), label: '训练' },
    { key: 'movement', icon: $r('app.media.ic_movement'), label: '动作库' },
    { key: 'stats', icon: $r('app.media.ic_stats'), label: '统计' },
    { key: 'profile', icon: $r('app.media.ic_profile'), label: '我的' }
  ];

  build() {
    Row() {
      ForEach(this.tabs, (tab: TabBarItem) => {
        Column() {
          Image(tab.key === this.currentTab ? tab.activeIcon || tab.icon : tab.icon)
            .width(24).height(24)
            .fillColor(tab.key === this.currentTab ? 'var(--color-primary)' : 'var(--color-neutral-300)')
          Text(tab.label)
            .fontSize('var(--font-small)')
            .fontColor(tab.key === this.currentTab ? 'var(--color-primary)' : 'var(--color-neutral-300)')
            .margin({ top: 'var(--space-xs)' })
        }
        .layoutWeight(1)
        .onClick(() => this.currentTab = tab.key)
      })
    }
    .width('100%')
    .height(56)
    .backgroundColor('var(--color-surface-primary)')
    .border({ width: { top: 0.5 }, color: 'var(--color-neutral-100)' })
    .padding({ bottom: 'var(--space-sm)' })
  }
}
```

### 2.5 StatBadge / 数据标签

用于“新纪录”、“约115kg”的轻量标记。

- **变体**： - `color: 'gold' | 'positive' | 'neutral'` - `size: 'small' | 'medium'`
- **禁止覆盖**：背景和文字颜色必须从语义 token 派生。

**代码示例**

typescript

```
@Component
export struct StatBadge {
  @Prop text: string = '';
  @Prop color: 'gold' | 'positive' | 'neutral' = 'neutral';
  @Prop size: 'small' | 'medium' = 'small';

  build() {
    Text(this.text)
      .fontSize(size === 'small' ? 'var(--font-small)' : 'var(--font-body)')
      .fontColor(color === 'gold' ? 'var(--color-new-record)' :
                 color === 'positive' ? 'var(--color-success)' : 'var(--color-text-secondary)')
      .backgroundColor(color === 'gold' ? 'rgba(255,215,0,0.15)' :
                       color === 'positive' ? 'rgba(76,175,80,0.15)' : 'var(--color-surface-secondary)')
      .borderRadius('var(--radius-sm)')
      .padding({ left: 'var(--space-xs)', right: 'var(--space-xs)', top: 2, bottom: 2 })
  }
}
```

## 3. 布局与栅格（Layout & Grid）

### 3.1 容器与断点

App 主要面向手机竖屏（360vp – 428vp 逻辑宽度），同时兼容平板横屏拓展。

| 断点名称 | 最小宽度（vp） | 列数 | 间距（gutter） | 页边距（margin） |
| --- | --- | --- | --- | --- |
| 断点名称 | 最小宽度（vp） | 列数 | 间距（gutter） | 页边距（margin） |
| `sm` | 320 | 4 | 16 | 16 |
| `md` | 600 | 8 | 24 | 24 |
| `lg` | 840 | 12 | 24 | 32 |

- **规则**：所有列表、卡片网格必须使用栅格列，不允许写死宽度值。
- 训练统计“本周概况”四组数据可使用 `GridRow`+`GridCol` 实现。

---

### 3.2 常用布局模式

- **训练计时器 + 动作列表**（训练进行中页）：顶部固定计时器，中部可滚动表单，底部固定“结束训练”按钮。使用 `Column` 嵌套 `Flex` 与 `Scroll`。
- **登录页**：主内容垂直居中，按钮撑满宽度，底部留社交登录入口。
- **动作库**：搜索栏 + 横向筛选标签（胸、背、腿…）+ 网格动作卡片，适合 `Tabs` / `Swiper` 结合 `Grid`。

## 4. 命名与组织规范（Naming & Structure）

### 4.1 文件命名

- 组件文件：`PascalCase`，如 `AppButton.ets`、`TrainingSummary.ets`。
- 工具类/样式：`kebab-case`，如 `color-tokens.css`、`spacing-utils.ets`。
- 资源图片：`ic_` 前缀 + 小写下划线，如 `ic_bench_press.png`。

---

### 4.2 CSS / 样式方法论

鸿蒙 ArkUI 推荐使用**声明式属性** + **样式变量** 的组合。不得使用内联硬编码样式。

- 抽取全局样式到 `common/styles/` 目录下的 `.ets` 或 `.css` 文件。
- 组件内部样式优先使用 `@Styles function` 或 `@Extend` 装饰器复用。
- 命名采用 `BEM` 思路：`block_element-modifier`（组件名作为 block）。

typescript

```
@Extend(Text) function cardTitle() {
  .fontSize('var(--font-title)')
  .fontColor('var(--color-text-primary)')
  .fontWeight(600)
}
```

## 5. 可访问性（Accessibility）

### 5.1 颜色对比度

- 正文文字（16sp）与背景对比度至少 **4.5:1**。
- 大标题（20sp 以上）对比度至少 **3:1**。
- 所有语义色（成功/错误）搭配白色文字时，需确保对比度达标；若不达标，必须提供辅助图标或下划线。

### 5.2 键盘焦点与触屏

- 所有可交互元素（Button、Input、Tab）必须具备**焦点态**样式，通常表现为 `outline` 或 `border-color` 改变。
- 焦点样式：`2vp` 的 `--color-primary` 实线边框，禁止使用 `outline:none` 而不提供替代样式。
- 触摸目标最小尺寸：`48vp × 48vp`（如“+ 添加组”按钮）。

### 5.3 语义化

- 图片必须添加 `alt` 或 `accessibilityText` 属性。
- 输入框必须绑定 `accessibilityText` 描述其用途。
- 使用 `ForEach` 渲染列表时，保证 `key` 稳定以支持屏幕阅读器焦点。
