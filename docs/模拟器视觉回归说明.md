# FitTracker 模拟器视觉回归说明

本项目使用 DevEco Studio 模拟器、HDC 和 Midscene 做可重复的视觉自动化回归。脚本只验证 FitTracker 自有本地流程，不接入 MuscleWiki 官方 API。

## 覆盖链路

固定训练闭环：

```text
启动 -> 目标设置 -> 首页 -> 训练预览 -> 训练执行 -> 复盘 -> 回顾 -> 调整目标
```

认证冒烟链路：

```text
注册/登录入口可见时：注册 -> 登录 -> 重启 -> 会话恢复 -> 首页/目标页分流
认证入口不可见时：确认当前页面仍可继续主流程
```

## 前置条件

1. DevEco Studio 模拟器已启动并解锁。
2. HDC 可用，且能看到设备：

```powershell
hdc version
hdc list targets
```

3. Midscene 模型环境变量已设置，或已写入本地 `.env`：

```powershell
$env:MIDSCENE_MODEL_BASE_URL='https://ark.cn-beijing.volces.com/api/v3'
$env:MIDSCENE_MODEL_API_KEY='your-api-key'
$env:MIDSCENE_MODEL_NAME='your-endpoint-or-model'
$env:MIDSCENE_MODEL_FAMILY='doubao-seed'
```

4. 已构建默认 HAP：

```powershell
$env:JAVA_HOME='C:\Program Files\Huawei\DevEco Studio\jbr'
$env:DEVECO_SDK_HOME='C:\Program Files\Huawei\DevEco Studio\sdk'
$env:PATH='C:\Program Files\Huawei\DevEco Studio\jbr\bin;C:\Program Files\Huawei\DevEco Studio\tools\hvigor\bin;C:\Program Files\Huawei\DevEco Studio\sdk\default\openharmony\toolchains;' + $env:PATH

& 'C:\Program Files\Huawei\DevEco Studio\tools\hvigor\bin\hvigorw.bat' assembleHap --mode module -p module=entry@default -p product=default
```

## 运行脚本

默认安装并启动应用：

```powershell
powershell -ExecutionPolicy Bypass -File tools/midscene-regression.ps1
```

指定设备：

```powershell
powershell -ExecutionPolicy Bypass -File tools/midscene-regression.ps1 -DeviceId '127.0.0.1:5555'
```

应用已手动安装时跳过安装：

```powershell
powershell -ExecutionPolicy Bypass -File tools/midscene-regression.ps1 -SkipInstall
```

默认包名来自 `AppScope/app.json5`：

```text
com.example.fittracker_opencode
```

## 视觉断言

脚本会在关键节点执行截图和断言：

- 启动后：FitTracker 可见，非空白屏，无崩溃弹窗。
- 完整训练闭环后：仍在 FitTracker 内，显示回顾、目标调整、首页、复盘或训练完成结果之一。
- 重启后：路由进入首页、目标设置、登录、注册或其他有效主流程页面。
- 认证冒烟后：页面仍可用，无崩溃弹窗。

Midscene 报告、截图和回放文件生成在 `midscene_run/`，该目录是本地运行产物，不提交到 Git。
脚本还会生成 `midscene_run/midscene-regression-summary.md`，用于快速查看本次执行状态、设备信息和最近一份报告路径。

每次真实执行后，按 `docs/midscene-regression-report-template.md` 汇总设备 ID、执行命令、失败截图路径和最终断言结果。

## 失败排查

| 问题 | 处理 |
| --- | --- |
| `hdc` 找不到 | 确认 DevEco Studio SDK toolchains 已加入 `PATH` |
| `hdc list targets` 为空 | 确认模拟器已启动、已解锁，并重启 HDC 服务 |
| HAP 找不到 | 先运行 `entry@default assembleHap`，或传入 `-HapPath` |
| Midscene API key 报错 | 检查 `MIDSCENE_MODEL_*` 环境变量或 `.env` |
| Midscene 返回 404 / `InvalidEndpointOrModel.NotFound` | 当前接入点不存在或无权限；更换可用接入点，或确认模型名称与火山引擎控制台一致 |
| Midscene 返回 429 / `SetLimitExceeded` | 火山引擎推理接入点额度或安全体验模式限制已触发；到火山引擎模型接入点页面调整/关闭限制，或换用可用模型接入点后重跑脚本 |
| 断言失败 | 打开 `midscene_run/` 报告，查看失败节点截图和回放 |
| 点击目标错误 | 优先修改脚本里的自然语言描述，使页面、按钮和目标状态更具体 |
