有恒运动 隐私政策

最后更新：2026-10-03（对应「云端账号与同步」版本 1.1.0（开发中）；版本号以 AppScope/app.json5 为准）

本政策描述 有恒运动（以下称"本应用"）当前版本对用户数据与设备能力的真实处理方式。本政策中的每一项陈述都与当前代码和配置一一对应：

- 权限口径以 entry/src/main/module.json5 为准；
- 网络与数据行为以 entry/src/main/ets/ 下的实现为准；
- 备份能力以 entry/src/main/resources/base/profile/backup_config.json 与 entry/src/main/ets/entrybackupability/EntryBackupAbility.ets 为准。

我们只声明已经实现的行为，也不遗漏已经实现的行为。 后续版本若新增任何数据采集、联网或权限申请，本政策会同步更新并在应用内提示。

一、核心承诺

1. 本地优先：训练计划、训练记录、身体数据、目标设置与应用设置默认只保存在你的设备本机；登录后开启的云同步是可选能力。
2. 最小权限：当前版本仅申请「网络访问」（ohos.permission.INTERNET）一项权限，用于账号登录与云同步；不申请位置、通讯录、短信、相机、麦克风、相册、日历等任何敏感权限。
3. 单一云服务：联网行为仅指向华为端云一体化服务（AppGallery Connect，以下称 AGC）——认证服务与云数据库；不集成广告 SDK、第三方统计 SDK 或社交分享 SDK。
4. 不收集额外信息：不采集设备唯一标识（OAID/AAID/UDID 等）、位置、通讯录、崩溃日志或使用行为埋点。
5. 可随时退出：你可以不登录使用全部本地功能；登录后也可随时退出登录并清除本机数据；云端快照可联系我们删除（见第八节）。

二、我们如何对待你的数据

| 数据类别 | 内容示例 | 存储位置 | 是否离开设备 |
| 账号与会话 | 用户 ID、登录令牌、昵称（会话快照） | 应用私有沙箱（Preferences）；账号标识由 AGC 认证服务管理 | 登录时（AGC 认证） |
| 训练计划 | 计划名称、动作、组次、周期 | 应用私有沙箱（Preferences） | 登录并开启同步后（AGC 云数据库） |
| 训练记录 | 每次训练的组次、重量、时长、完成度 | 应用私有沙箱（Preferences） | 同上 |
| 目标设置 | 目标类型、强度、周期 | 应用私有沙箱（Preferences） | 同上 |
| 用户资料 | 昵称、头像标识、重量单位偏好 | 应用私有沙箱（Preferences） | 同上 |
| 身体数据 | 体重、体脂等记录 | 应用私有沙箱（Preferences） | 否（当前版本不参与云同步） |
| 应用设置 | 单位、语言、周开始日、各类开关状态 | 应用私有沙箱（Preferences） | 否 |

上述本地数据均写入应用私有沙箱，其他应用无法直接读取。云端数据（登录并同步后）写入你自己的 AGC 账号数据空间，按用户 ID 隔离，AGC 侧权限已配置为「仅数据创建者读写」。

三、我们不收集什么

当前版本不进行下列任何行为：

- 不注册、不上报设备唯一标识（OAID/AAID/UDID 等）；
- 不采集崩溃日志、埋点或使用行为统计；
- 不申请位置、通讯录、短信、相机、麦克风、相册、日历等任何敏感权限；
- 不集成广告 SDK、第三方统计 SDK 或社交分享 SDK（云端能力仅使用华为 AGC 认证服务与云数据库）；
- 不包含内嵌浏览器（WebView）或任何远程内容加载。

四、系统权限说明

entry/src/main/module.json5 当前声明 1 项权限：

- ohos.permission.INTERNET（网络访问）：用于账号登录（AGC 认证服务）与云同步（AGC 云数据库）。不登录时该权限不被使用，应用全部本地功能离线可用。

五、网络访问说明

登录与云同步是当前版本唯一的网络行为，全部指向华为 AGC：

- 认证服务：手机验证码 / 邮箱密码 / 华为账号登录时，凭据（手机号、邮箱或华为账号标识）提交至 AGC 认证服务完成身份验证；登录令牌由 AGC 颁发并管理。
- 云数据库：登录并开启同步后，应用将训练数据整包快照（目标、计划、训练记录、用户资料，见第二节）上传至 AGC 云数据库（中国大陆区域），用于跨设备恢复；上行时机为登录成功、冷启动已登录与训练完成（自动同步开启时），也可在「账号与同步」页手动同步。
- 沙盒降级：工程未配置 AGC 凭据时（如本地开发构建），应用自动进入演示模式，所有"云端"读写均在本机沙盒内完成，不发起网络请求。

动作演示素材（GIF、图片）随安装包内置在 entry/src/main/resources/rawfile/ 中，运行时从本地读取，不联网下载。不登录时，本应用的训练记录、动作库浏览与复盘功能完全离线可用。

六、关于设置页中的开关（如实说明）

设置页包含若干数据相关开关，它们当前的行为如下：

| 设置项 | 当前实际行为 |
| 训练数据同步 | 真实生效：开启后，登录状态下自动触发云同步（登录成功、冷启动、训练完成）；关闭后不再自动触发，仍可在「账号与同步」页手动同步。未登录时开启会提示先登录 |
| 匿名使用数据 | 仅记录开关状态，不采集、不上报任何使用数据 |
| 健康数据授权 | 仅作界面展示，未申请任何健康类权限，未读取系统健康数据 |
| 训练提醒 / 成就提醒 | 仅记录开关状态，当前未注册系统通知 |
| 声音与震动 | 仅记录开关状态 |
| 训练中屏幕常亮 | 仅记录开关状态 |

以上开关的存储同样只发生在设备本机。这些能力若在未来版本进一步接入（例如接入系统通知或健康数据），本政策会先行更新并再次征得你的同意。

七、数据备份与迁移

- 手动备份/恢复：你可以使用应用内备份功能，将数据导出为本地 JSON 备份包，保存在你选择的本地位置。该文件由你自行保管，应用不会自动上传。
- 云同步（登录后）：与本地备份不同，云同步自动将"目标、计划、训练记录、用户资料"快照存入你自己的 AGC 账号数据空间（按用户 ID 隔离），用于跨设备恢复；不包含身体数据、训练草稿、内容库与媒体缓存。
- 系统备份：本应用声明了 allowToBackupRestore，若你在系统设置中开启了云备份，操作系统可能在执行备份时把应用数据一并纳入并由系统上传到你自己的云账号。这一传输由系统与你的账号设置控制，应用自身不发起、不干涉。你可以通过在系统设置中关闭云备份来阻止此类传输。

八、数据删除

- 你可以在系统"应用管理"中清除本应用数据，或卸载本应用，这将删除设备上的全部本地数据。
- 退出登录会清除本机业务数据（目标、计划、训练记录、用户资料），但不会自动删除云端的同步快照（供你再次登录时恢复）。
- 云端副本：当前版本未提供应用内删除云端数据的入口；如需删除云端快照，请通过第十一节的联系方式提出，我们会在核实账号身份后处理。
- 建议在清除或卸载前，先使用应用内备份功能导出备份包。

九、未成年人

本应用是通用的健身训练记录工具，不面向 14 周岁以下儿童专门设计。若你是未成年人，请在监护人指导下使用。

十、政策更新

本政策可能随版本更新而调整。任何涉及数据采集、权限或联网行为的变化，都会先更新本政策并同步应用内提示，我们不会在你不知情的情况下改变数据处理方式。
