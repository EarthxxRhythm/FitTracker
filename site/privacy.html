菲特（FitTracker） 隐私政策

最后更新：2026-10-28（版本号随应用版本更新，以 AppScope/app.json5 为准）

本政策描述 菲特（FitTracker，以下称"本应用"）当前版本对用户数据与设备能力的真实处理方式。本政策中的每一项陈述都与当前代码和配置一一对应：

  • 权限口径以 entry/src/main/module.json5 为准；
  • 网络与数据行为以 entry/src/main/ets/ 下的实现为准；
  • 备份能力以 entry/src/main/resources/base/profile/backup_config.json 与 entry/src/main/ets/entrybackupability/EntryBackupAbility.ets 为准。

我们只声明已经实现的行为，也不遗漏已经实现的行为。 后续版本若新增任何数据采集、联网或权限申请，本政策会同步更新并在应用内提示。

一、核心承诺

  1. 数据默认留在本机：使用应用需先创建账号；登录后，训练计划、训练记录、身体数据、目标设置与应用设置保存在你的设备本机，并可跨设备同步。
  2. 最小权限：当前版本仅申请「网络访问」（ohos.permission.INTERNET）与「振动」（ohos.permission.VIBRATE）两项权限——前者用于账号登录与云同步，后者仅在训练完成一组时提供触觉反馈（不采集数据、不联网，可在设置页关闭）；不申请位置、通讯录、短信、相机、麦克风、相册、日历等任何敏感权限。
  3. 云服务范围：联网行为指向本应用自建的身份与数据服务（自托管 Supabase，部署于本应用自有的境内云服务器）——认证服务与数据存储；使用微信 / QQ / 华为账号登录时，会调用对应官方 SDK 完成授权（见第五节），仅获取用于识别账号的标识与昵称，不采集通讯录、好友列表或任何社交内容；不集成广告 SDK、第三方统计 SDK、第三方分享或支付 SDK。
  4. 不收集额外信息：不采集设备唯一标识（OAID/AAID/UDID 等）、位置、通讯录、崩溃日志或使用行为埋点。
  5. 可随时退出：应用需登录后使用，数据始终保存在你的设备本机；你可以随时退出登录（本机数据保留）；云端快照可联系我们删除（见第八节）。

二、我们如何对待你的数据

数据类别内容示例存储位置是否离开设备

训练计划计划名称、动作、组次、周期应用私有沙箱（Preferences）登录后自动同步（自托管 Supabase）

三、我们不收集什么

当前版本不进行下列任何行为：

  • 不注册、不上报设备唯一标识（OAID/AAID/UDID 等）；
  • 不采集崩溃日志、埋点或使用行为统计；
  • 不申请位置、通讯录、短信、相机、麦克风、相册、日历等任何敏感权限；
  • 不集成广告 SDK、第三方统计 SDK，也不集成第三方分享或第三方支付 SDK（云端能力仅使用自托管 Supabase；登录时调用微信 / QQ / 华为账号官方 SDK，用途与数据范围见第五节）；
  • 不包含内嵌浏览器（WebView）或任何远程内容加载。

四、系统权限说明

entry/src/main/module.json5 当前声明 2 项权限：

  • ohos.permission.INTERNET（网络访问）：用于账号登录（自托管 Supabase 上的认证服务）与云同步。未登录时该权限不被使用。
  • ohos.permission.VIBRATE（振动）：用于训练完成一组时的触觉振动反馈（30ms 短促振动）；不采集数据、不联网；可在设置页「声音与震动」中关闭。

选择头像图片时使用系统图库选择器，应用不申请相册（媒体）读取权限：选择器只把你主动选中的那一张图片交给本应用，本应用无法访问相册中的其他内容。头像会压缩（正方形、256×256、JPEG）后保存在应用私有目录，并随云同步快照上传（见第五节）。

训练提醒与成就提醒所需的系统级代理提醒能力（ohos.permission.PUBLISH_AGENT_REMINDER）当前未申请，提醒以应用内通知形式工作（见第六节）。

五、网络访问说明

登录与云同步是当前版本唯一的网络行为，全部指向本应用自建的服务端（自托管 Supabase，部署于本应用自有的境内云服务器）：

  • 认证服务：手机验证码 / 邮箱密码登录时，凭据（手机号或邮箱）提交至自建 Supabase 认证服务完成身份验证；登录令牌由该服务颁发并管理。
  • 第三方登录：选择微信 / QQ / 华为账号登录时，先由对应官方 SDK 在客户端完成授权并取得一次性授权码；该授权码随后提交至本应用服务端，由服务端凭密钥向第三方换取账号标识，用于建立本应用的登录会话。换取过程所需的密钥只保存在服务端，不下发到客户端。
  • 云数据：登录后，应用将训练数据整包快照（目标、计划、训练记录、用户资料，见第二节）上传至自托管 Supabase，用于跨设备恢复；上行时机为登录成功、冷启动已登录与训练完成，均为自动同步。
  • 沙盒降级：工程未配置 Supabase 凭据时（如本地开发构建），应用自动进入演示模式，所有"云端"读写均在本机沙盒内完成，不发起网络请求。

第三方登录 SDK 说明（如实披露）：本应用的第三方登录方式及对应 SDK 如下：

登录方式调用的 SDK用途获取的信息
微信微信 OpenSDK（腾讯）拉起微信完成授权，取得一次性授权码账号唯一标识（unionid）、昵称
QQQQ 互联 OpenSDK（腾讯）拉起 QQ 完成授权，取得一次性授权码账号唯一标识（openid）、昵称
华为账号Account Kit（华为）拉起华为账号完成授权，取得一次性授权码账号唯一标识（UnionID）、昵称

上述 SDK 仅用于完成授权与获取账号标识，不采集你的通讯录、好友列表、聊天内容或任何社交数据；应用未申请任何社交类敏感权限。若你选择不使用这些方式，可完全使用手机验证码或邮箱密码登录。

动作演示素材（GIF、图片）随安装包内置在 entry/src/main/resources/rawfile/ 中，运行时从本地读取，不联网下载。未登录时应用停留在登录页，不进入主界面。

六、关于设置页中的开关（如实说明）

设置页包含若干数据相关开关，它们当前的行为如下：

设置项当前实际行为
训练数据同步真实生效：登录状态下自动触发云同步（登录成功、冷启动、训练完成）；未登录时不发起云同步
匿名使用数据仅记录开关状态，不采集、不上报任何使用数据
健康数据授权仅作界面展示，未申请任何健康类权限，未读取系统健康数据
训练提醒真实生效：开启后每天 19:30 提醒训练；当天已完成训练或为休息日则不打扰。当前以应用内通知形式工作（系统代理提醒能力获批后升级为系统级提醒，应用退出后仍可提醒）
成就提醒真实生效：连续训练达到 3 / 7 / 14 / 30 天时发送「连续训练达成」通知
声音与震动真实生效：训练完成一组时给出一次 30ms 短促振动（暂无音效）；开关关闭时不振动
训练中屏幕常亮真实生效：训练过程中保持屏幕常亮（进入训练开启、退出恢复；不采集数据、不申请权限）

以上开关的存储同样只发生在设备本机；训练提醒与成就提醒的通知内容在本机生成，不包含任何上传数据。这些能力若在未来版本进一步接入（例如系统级代理提醒或健康数据），本政策会先行更新并再次征得你的同意。

七、数据同步与迁移

  • 云同步（登录后）：与本地备份不同，云同步自动将快照存入自托管 Supabase 的账号数据空间（按用户 ID 隔离），用于跨设备恢复。同步范围包括：目标、计划、训练记录、用户资料（昵称/头像/单位偏好/训练经验）、身体档案（身高/性别/出生年份）与身体数据（体重/围度/体成分）；不包含训练草稿、内容库与媒体缓存。
  • 系统备份：本应用声明了 allowToBackupRestore，若你在系统设置中开启了云备份，操作系统可能在执行备份时把应用数据一并纳入并由系统上传到你自己的云账号。这一传输由系统与你的账号设置控制，应用自身不发起、不干涉。你可以通过在系统设置中关闭云备份来阻止此类传输。

八、数据删除

  • 你可以在系统"应用管理"中清除本应用数据，或卸载本应用，这将删除设备上的全部本地数据。
  • 退出登录会清除本机业务数据（目标、计划、训练记录、用户资料），但不会自动删除云端的同步快照（供你再次登录时恢复）。
  • 云端副本：当前版本未提供应用内删除云端数据的入口；如需删除云端快照，请通过第十一节的联系方式提出，我们会在核实账号身份后处理。
  • 建议在清除或卸载前，先使用应用内备份功能导出备份包。

九、未成年人

本应用是通用的健身训练记录工具，不面向 14 周岁以下儿童专门设计。若你是未成年人，请在监护人指导下使用。

十、政策更新

本政策可能随版本更新而调整。任何涉及数据采集、权限或联网行为的变化，都会先更新本政策并同步应用内提示，我们不会在你不知情的情况下改变数据处理方式。
