# Typography Spec

## Role
Typography is one of the main sources of perceived quality in FitTracker. If typography is weak, the interface will still feel like an engineering product even if colors and cards improve.

Typography in FitTracker must create:
- hierarchy
- pace
- trust
- density control
- premium restraint

---

## Core Principles

1. Text should create hierarchy before boxes and decoration do.
2. Numbers and status labels are especially important in this product.
3. The UI should feel precise, not loud.
4. Type should support scanning in training contexts, not force reading.
5. A premium interface uses fewer stronger typographic decisions, not many weak ones.

---

## Typographic Tone
FitTracker typography should feel:
- modern
- controlled
- readable
- dense enough for utility
- calm enough for premium quality

It should not feel:
- playful consumer fitness
- over-stylized luxury fashion
- medical dashboard sterile
- gamer HUD compressed

---

## Hierarchy Model

### Display / Hero
Use for:
- major page framing
- key high-value metrics
- dominant page numbers

Feel:
- strong
- spacious
- deliberate

### Title
Use for:
- section headings
- primary card headings
- page titles

Feel:
- clear
- authoritative
- compact enough for mobile

### Body
Use for:
- primary content text
- most explanatory lines
- action support copy

Feel:
- calm
- readable
- unpretentious

### Small / Caption
Use for:
- metadata
- supporting hints
- low-priority labels
- helper text

Feel:
- quiet but still legible

### Micro / Label
Use for:
- compact labels
- chips
- tiny supporting UI text

Feel:
- efficient, not decorative

---

## Numeric Emphasis
This product is data-heavy. Numeric typography matters more than average.

Numbers for:
- training volume
- completed sets
- duration
- PR values
- trend deltas
- heatmap summaries

should feel more deliberate and more visually stable than ordinary text.

Rules:
- key numbers should have stronger hierarchy than nearby labels
- numbers should not be hidden inside weak secondary text blocks
- PR and high-value deltas should feel premium, not flashy

---

## Weight Guidance
- primary metrics and key titles: medium to semibold
- most body text: regular to medium
- metadata: regular
- avoid too many weight jumps on the same screen

Too many bold elements reduce the premium feeling and flatten hierarchy.

---

## Spacing and Rhythm Rules
Typography should create rhythm through:
- clear heading/body separation
- enough air between major sections
- tighter grouping inside one semantic block
- stronger separation between primary and secondary information

If text feels dense, solve it with hierarchy and grouping before shrinking fonts.

---

## Home Page Typography Goal
The Home page should use typography to make these obvious instantly:
- today’s workout
- the main next action
- whether today is active or rest
- what contextual information is secondary

If the user must read multiple similar-weight text blocks, hierarchy has failed.

---

## Active Workout Typography Goal
The Active Workout page should use typography to make these obvious instantly:
- current workout state
- current exercise identity
- set-entry labels
- completion feedback
- key numeric feedback like 1RM and counts

The page should read like a control surface, not a content page.

---

## Review Typography Goal
The Review page should use typography to create a premium data-reading experience:
- trends first
- record signals second
- history detail third

If the page feels like all statistics are equally loud, typography is failing.

---

## Failure Signs
Typography is not acceptable if:
- everything is roughly the same size and weight
- titles are bold but still weak in hierarchy
- body text is too bright or too dominant
- key numbers do not stand out enough
- the page reads like a generic dashboard template

---

## Success Criteria
Typography is correct when:
- the user can scan without friction
- key actions and metrics are obvious
- the UI feels more premium and intentional
- the product feels designed rather than merely styled
