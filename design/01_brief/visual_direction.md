# FitTracker Visual Direction

## Primary Visual Theme
**Cold Emerald Performance / 冷感青翠绿**

This is the fixed design direction for FitTracker.

## Desired Emotional Tone
The interface should feel:
- dark
- calm
- premium
- precise
- restrained
- capable
- performance-oriented
- trustworthy

It should resemble a **high-end training data system** or a **night-mode performance control interface**, not a generic consumer fitness app.

## Core Style Keywords
- black-green deep base
- cool emerald highlights
- subtle metallic silver accents
- very sparing warm gold accents
- layered dark surfaces
- instrument-panel clarity
- premium training tool

## What The Interface Should Communicate
When a user sees the product, they should feel:
- this is serious
- this is refined
- this is built for training, not entertainment
- this system helps me act and understand progress

## What The Interface Should Avoid
Do **not** drift toward:
- neon green
- esports / cyberpunk
- generic dark SaaS dashboard
- over-glossy luxury black-and-gold
- fitness-marketing landing page aesthetics
- heavy glassmorphism
- gradient-heavy concept UI
- decoration that reduces readability

## Visual Hierarchy Philosophy
FitTracker should always make the following obvious:

### Home
- what today’s workout is
- what the primary action is
- what current progress or status matters most

### Preview
- what the workout structure is
- what the user is about to do
- where the start action is

### Active Workout
- what the current exercise is
- where to record sets, weight, and reps
- what is completed vs in progress
- what feedback matters now

### Summary
- what was achieved in this session
- what is valuable enough to remember
- whether any PR or progress happened

### Review
- whether long-term progress is happening
- what the trends say
- what record/history information deserves focus

## Signature Style Markers
To create a recognizable FitTracker visual identity, prefer:
- a deep dark background with multiple green-black surface layers
- bright cool green only for focal information and active states
- silver for structure, precision, secondary system accents
- gold only for rare/high-value states such as PR or premium summary emphasis
- cards that feel like refined dark panels, not floating toy blocks
- strong typographic hierarchy instead of excessive decoration

## Key Rule For Accent Use
Green is the **energy signal**, not the page color.

Use green to indicate:
- the primary CTA
- active input state
- completion state
- meaningful trend improvement
- key chart lines or peaks
- high-intensity heatmap cells
- critical focus data

Do not use green everywhere.

## Quality Bar
A successful FitTracker redesign should not merely feel “more unified.” It should feel like the product has made a clear jump from an engineering-first interface to a **real premium product experience**.
