# Page Headers Spec

## Role
Page headers establish the tone, hierarchy, and first impression of each FitTracker screen. They should frame the page clearly without wasting vertical space or becoming decorative hero sections.

A strong header makes the page feel productized. A weak header makes the page feel like a stitched-together tool.

---

## Core Principles

1. Headers should establish purpose immediately.
2. Headers must support page hierarchy, not compete with the main content.
3. Headers should feel premium and deliberate, not ornamental.
4. Different pages can vary in intensity, but they must feel like the same product family.

---

## Header Tone
Headers should feel:
- confident
- calm
- structured
- refined
- compact enough for mobile

They should not feel:
- like landing-page heroes
- like generic settings titles
- like oversized decorative banners

---

## Header Structure
A header may contain:
- page title
- small eyebrow / context label when useful
- one-line supporting explanation
- compact status chip or high-level state cue

Not every page needs every element. Use only what supports clarity.

---

## Page-Specific Intent
### Home
Header should frame the page as a training command surface and reinforce readiness.

### Workout Preview
Header should create a preparation mood and clarify what session is about to begin.

### Active Workout
Header should feel tighter and more operational; it must not push the critical recording area too far down.

### Workout Summary
Header should create a sense of closure and value.

### Review
Header should frame the page as a performance and progress surface.

### Exercise Detail
Header should establish movement identity and instructional trust.

---

## Visual Rules
- Titles should use strong typographic hierarchy, not oversized styling.
- Supporting copy should remain compact.
- Green should only appear if the header includes a meaningful active or status signal.
- Do not overuse decorative separators, gradients, or glow.
- Spacing below the header should make the top content block feel intentionally introduced.

---

## Height Discipline
Headers must not consume too much of the first viewport.
Especially on task-oriented pages like Active Workout, header height should be disciplined so the main action area stays visible early.

---

## Success Criteria
Headers are correct when:
- the page purpose is obvious immediately
- the top of the page feels intentional and premium
- header tone matches the page role
- headers across pages feel consistent without becoming repetitive

---

## Failure Signs
Headers are not acceptable if:
- they are visually generic
- they are too tall for mobile task flow
- they rely on decorative styling instead of hierarchy
- different pages feel like different apps at the top level
