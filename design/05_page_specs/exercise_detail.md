# Exercise Detail Page Spec

## Page Role
The Exercise Detail page is the **professional training knowledge card** of FitTracker.

It should help the user understand the movement clearly and trust the content, while staying visually aligned with the premium system feel of the rest of the app.

---

## Primary UX Goal
The user should quickly understand:
1. what this exercise is
2. how to perform it
3. what to watch out for
4. what support media or supporting context exists
5. how this exercise relates to their training context or records

The page should feel useful, credible, and structured.

---

## Core Visual Goal
This page should feel like a **high-quality training manual panel**, not an article page and not a generic info dump.

It should feel:
- professional
- clear
- grounded
- premium
- instructional without being sterile

---

## Information Hierarchy

### Level 1: Exercise identity
This should establish:
- exercise name
- movement identity
- top-level context or status

### Level 2: Essential training knowledge
This includes:
- steps
- cues
- common mistakes
- safety notes

These should be easy to scan and clearly separated.

### Level 3: Media and supporting content
This includes:
- cover / video / metadata
- source note
- license note
- optional premium content cues

Media should support understanding, not dominate the whole page.

### Level 4: Related and historical context
This includes:
- alternatives
- personal records
- related training context

These should be useful but secondary to the instructional core.

---

## Required Aesthetic Outcomes
The page should not look like:
- a blog article
- a plain encyclopedia entry
- a generic content list
- a random card stack with no reading rhythm

The page should look like:
- a premium exercise knowledge panel
- a refined movement detail surface
- a structured instructional tool

---

## Content Presentation Rules
- Long text should be broken into clear modules.
- Steps and cues should feel instructional and easy to follow.
- Mistakes and safety notes should feel important but not alarmist.
- Media sections should be clearly framed and visually integrated.
- Personal-record information should feel like useful supporting context, not page clutter.

---

## Color and Surface Rules
- Use dark surfaces to frame content blocks.
- Use green only for interaction emphasis, active media state, or meaningful action focus.
- Use gold only for rare value highlights such as records or premium cues.
- Keep instructional text highly readable and visually calmer than CTA surfaces.

---

## Page Success Criteria
The Exercise Detail redesign is successful only if:
- the page feels more like a premium training manual than a content page
- information is easy to scan without becoming sterile
- media and records support the page instead of overwhelming it
- the page clearly belongs to the same product family as Home, Active Workout, and Review

---

## Failure Signs
The redesign is not acceptable if:
- the page still reads like a generic article
- content is visually flat
- media dominates without helping structure
- records, alternatives, and instructional content compete without hierarchy
- the page has more decoration but not more instructional clarity
