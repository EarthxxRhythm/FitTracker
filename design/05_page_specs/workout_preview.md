# Workout Preview Page Spec

## Page Role
The Workout Preview page is the **preparation surface** between intent and action. It should help the user understand what today's workout involves before entering the execution flow.

---

## Primary UX Goal
The user should quickly understand:
1. what today's session is
2. what exercises and structure are included
3. what they are about to do
4. where to start

The page should create clarity and readiness, not friction.

---

## Core Visual Goal
The Workout Preview page should feel like a **mission prep panel**.
Not a content page, not a plain list, and not a passive summary.

It should feel:
- organized
- anticipatory
- calm
- clear
- premium

---

## Information Hierarchy

### Level 1: Session identity and primary CTA
The top of the page should make clear:
- what workout this is
- what its focus is
- where to begin

### Level 2: Workout structure
This includes:
- exercise list
- set/reps structure
- rest or guidance context
- anything needed to mentally prepare

### Level 3: Supporting details
This includes:
- notes
- optional detail entries
- paths into exercise detail

These should help understanding without diluting the main start flow.

---

## Required Aesthetic Outcomes
The page should not look like:
- a plain list of exercises
- a generic summary page
- a weak transitional page with no identity

The page should look like:
- a deliberate preparation surface
- a page that creates momentum toward starting the workout
- a premium system panel that makes the coming session feel coherent

---

## CTA Rules
There must be one clear primary CTA for entering the workout flow.
Supporting actions such as viewing exercise details should remain secondary.

The user should not have to decide among multiple equally loud actions before starting.

---

## Surface and Color Rules
- Stronger surfaces may be used for the top session summary or start zone.
- Supporting exercise cards should stay organized and restrained.
- Green should emphasize the start action and key active cues.
- The page should feel calmer than Active Workout, but still clearly action-oriented.

---

## Page Success Criteria
The Workout Preview redesign is successful only if:
- the user understands the session quickly
- the page creates readiness and momentum
- the main start action is obvious
- supporting exercise detail paths do not compete with the primary flow
- the page visually belongs between Home and Active Workout in the same product family

---

## Failure Signs
The redesign is not acceptable if:
- it still feels like a basic list page
- the start CTA is visually weak
- the screen feels passive rather than preparatory
- information is present but not clearly staged
- the page looks unrelated to the rest of the system
