# Workout Summary Page Spec

## Page Role
The Workout Summary page is the **session closure surface** of FitTracker. It turns the just-finished workout into a clear, valuable summary and bridges the user into reflection or next steps.

---

## Primary UX Goal
The user should quickly understand:
1. what was completed
2. what was achieved
3. whether anything meaningful happened
4. where to go next

The page should create a sense of completion and value, not just dump data.

---

## Core Visual Goal
The Workout Summary page should feel like a **premium post-session result card**.
Not a receipt. Not a generic confirmation page. Not a plain list of fields.

It should feel:
- resolved
- rewarding
- calm
- high-value
- intentional

---

## Information Hierarchy

### Level 1: Session outcome
This should establish:
- workout completed state
- main completion summary
- strongest top-level achievement cue

### Level 2: Key result metrics
This includes:
- completed sets
- volume / duration / notable numbers
- meaningful progress or PR signal

### Level 3: Next actions
This includes:
- return home
- go to review
- continue into broader reflection flow

These actions should be clear, but should not overshadow the result summary itself.

---

## Required Aesthetic Outcomes
The page should not look like:
- a confirmation dialog stretched into a full page
- a stats list with no emotional resolution
- a weak bridge screen between workout and review

The page should look like:
- a deliberate closure surface
- a result summary with weight and value
- a page that makes the session feel recorded and real

---

## Reward Without Flashiness
The page should communicate accomplishment, but in a restrained way.
Use:
- strong hierarchy
- a premium summary surface
- selective emphasis for standout results

Do not use:
- loud celebratory effects
- excessive green everywhere
- gamified fireworks
- cheap motivational graphics

---

## Surface and Color Rules
- A stronger result summary card may anchor the page.
- Green should emphasize completion and key positive outcome.
- Gold should be reserved for rare high-value signals like PR.
- Supporting details should remain quieter than the main result block.

---

## Page Success Criteria
The Workout Summary redesign is successful only if:
- the user feels the session has been cleanly closed
- the main result is obvious immediately
- meaningful achievements are visible without overstatement
- the page smoothly leads into Home or Review
- the page visually belongs to the same premium system as Active Workout and Review

---

## Failure Signs
The redesign is not acceptable if:
- it feels like a generic confirmation page
- it lists results without hierarchy
- next actions are clearer than the result itself
- the session does not feel meaningfully summarized
- the page is polished but emotionally flat
