菲特（FitTracker） 隐私政策

最后更新：2026-10-28（Android 版；版本号以应用内「设置」显示的版本为准）

本政策描述 菲特（FitTracker，以下称"本应用"）当前版本对用户数据与设备能力的真实处理方式。本政策中的每一项陈述都与当前代码和配置一一对应：

- 权限口径以应用清单（AndroidManifest.xml）为准；
- 网络与数据行为以应用实现为准；
- 系统备份能力以 allowBackup 声明为准（见第七节）。

我们只声明已经实现的行为，也不遗漏已经实现的行为。 后续版本若新增任何数据采集、联网或权限申请，本政策会同步更新并在应用内提示。

一、核心承诺

1. 数据默认留在本机：使用应用需先创建账号；登录后，训练计划、训练记录、身体数据、目标设置与应用设置保存在你的设备本机，并可跨设备同步。
2. 最小权限：当前版本共申请 4 项权限——「网络访问」（android.permission.INTERNET），用于账号登录与云同步；「震动」（android.permission.VIBRATE），用于训练触觉反馈；「发送通知」（android.permission.POST_NOTIFICATIONS），用于训练提醒与成就提醒的本地通知；「查看网络连接」（android.permission.ACCESS_NETWORK_STATE），仅读取当前网络连通状态，供第三方登录 SDK 校验网络与诊断使用，不读取任何连接内容。不申请位置、通讯录、短信、相机、麦克风、相册、日历等任何敏感权限。
3. 云服务范围：联网行为指向本应用自建的身份与数据服务（自托管 Supabase，部署于本应用自有的境内云服务器）——认证服务与数据存储；使用微信 / QQ 登录时，会调用对应官方 SDK 完成授权（见第五节），仅获取用于识别账号的标识与昵称，不采集通讯录、好友列表或任何社交内容；不集成广告 SDK、第三方统计 SDK、第三方分享或支付 SDK。
4. 不收集额外信息：不采集设备唯一标识、位置、通讯录、崩溃日志或使用行为埋点。
5. 可随时退出：应用需登录后使用，数据始终保存在你的设备本机；你可以随时退出登录（本机数据保留）；云端快照可联系我们删除（见第八节）。

二、我们如何对待你的数据

| 数据类别 | 内容示例 | 存储位置 | 是否离开设备 |
| 账号与会话 | 用户 ID、登录令牌、昵称（会话快照） | 应用私有存储；账号标识由 Supabase 认证服务管理 | 登录时（Supabase 认证） |
| 训练计划 | 计划名称、动作、组次、周期 | 应用私有存储 | 登录并同步后（自建服务器数据库） |
| 训练记录 | 每次训练的组次、重量、时长、完成度 | 应用私有存储 | 同上 |
| 目标设置 | 目标类型、强度、周期 | 应用私有存储 | 同上 |
| 用户资料 | 昵称、头像（图片或头像标识）、重量单位偏好、训练经验 | 应用私有存储（头像图片另存于应用私有目录） | 同上 |
| 身体数据 | 体重、体脂等记录 | 应用私有存储 | 否（当前版本不参与云同步） |
| 应用设置 | 单位、语言、周开始日、各类开关状态 | 应用私有存储 | 否 |

上述本地数据均写入应用私有存储，其他应用无法直接读取。云端数据（登录并同步后）写入你的 Supabase 账号数据空间，按用户 ID 隔离，云端权限已配置为「仅数据创建者读写」（行级安全策略）。

三、我们不收集什么

当前版本不进行下列任何行为：

- 不注册、不上报设备唯一标识；
- 不采集崩溃日志、埋点或使用行为统计；
- 不申请位置、通讯录、短信、相机、麦克风、相册、日历等任何敏感权限；
- 不集成广告 SDK、第三方统计 SDK，也不集成第三方分享或第三方支付 SDK（云端能力仅使用自托管 Supabase；登录时调用微信 / QQ 官方 SDK，用途与数据范围见第五节）；
- 不包含内嵌浏览器（WebView）或任何远程内容加载。

四、系统权限说明

AndroidManifest.xml 当前声明 4 项权限：

- android.permission.INTERNET（网络访问）：用于账号登录（自建服务器上的认证服务）与云同步（自建服务器上的数据库）。未登录时该权限不被使用。
- android.permission.VIBRATE（震动）：用于训练触觉反馈——训练中每记下一组时给一次短促震动，由设置页「声音与震动」开关控制。该权限为普通权限，声明即生效，不在运行时弹出请求。
- android.permission.POST_NOTIFICATIONS（发送通知）：用于把训练提醒与成就提醒作为本地通知投递到你的设备。Android 13 及以上需在运行时授予；未授予时对应开关无法开启，你若在系统设置中撤销，通知即停止。
- android.permission.ACCESS_NETWORK_STATE（查看网络连接）：仅读取当前网络连通状态，供第三方登录 SDK（QQ / 微信）校验网络与诊断使用，不读取任何连接内容、不采集数据。

选择头像图片时使用系统照片选择器，应用**不申请相册 / 存储权限**：选择器只把你主动选中的那一张图片交给本应用，本应用无法访问相册中的其他内容。头像会压缩（正方形、256×256、JPEG）后保存在应用私有目录，并随云同步快照上传。

五、网络访问说明

登录与云同步是当前版本唯一的网络行为，全部指向 Supabase：

- 认证服务：手机验证码 / 邮箱密码登录时，凭据（手机号或邮箱）提交至 Supabase 认证服务完成身份验证；登录令牌由 Supabase 颁发并管理。
- 云数据库：登录后自动同步，应用将训练数据整包快照（目标、计划、训练记录、用户资料，见第二节）上传至 Supabase 云数据库，用于跨设备恢复；上行时机为登录成功、冷启动已登录与训练完成（均为自动同步）。
- 沙盒降级：工程未配置 Supabase 凭据时（如本地开发构建），应用自动进入演示模式，所有"云端"读写均在本机沙盒内完成，不发起网络请求。

动作演示素材（GIF、图片）随安装包内置，运行时从本地读取，不联网下载。不登录时，本应用的训练记录、动作库浏览与回顾功能完全离线可用。

六、关于设置页中的开关（如实说明）

设置页包含若干数据相关开关，它们当前的行为如下：

| 设置项 | 当前实际行为 |
| 训练数据同步 | 真实生效：登录状态下自动触发云同步（登录成功、冷启动、训练完成）；未登录时不发起云同步 |
| 匿名使用数据 | 仅记录开关状态，不采集、不上报任何使用数据 |
| 健康数据授权 | 仅作界面展示，未申请任何健康类权限，未读取系统健康数据 |
| 训练提醒 / 成就提醒 | 真实生效：开启后在设备本机注册本地通知——周期检查任务（WorkManager，24 小时周期，期望时刻约 19:30）在当天没有训练记录、且当天是当前计划安排的训练日时提醒你训练；训练完成且达成连续训练里程碑时投递成就通知。通知只在你的设备上产生与展示，不为此把任何数据传出设备。Android 13 及以上需授予通知权限，未授予则开关无法开启 |
| 声音与震动 | 真实生效：开启后训练中每记下一组即给一次短促触觉反馈（震动）；关闭则不震不响。当前版本无音效素材，仅震动 |
| 训练中屏幕常亮 | 真实生效：训练执行页打开期间，开关开启时保持屏幕常亮；离开该页即释放 |

以上开关的存储同样只发生在设备本机。这些能力若在未来版本进一步扩展（例如更深地接入系统通知或健康数据），本政策会先行更新并再次征得你的同意。

七、数据同步与迁移

- 云同步（登录后）：与本地存储不同，云同步自动将"目标、计划、训练记录、用户资料"快照存入本应用自建服务器上的账号数据空间（按用户 ID 隔离），用于跨设备恢复；不包含身体数据、训练草稿、内容库与媒体缓存。
- 系统备份：本应用已声明 allowBackup（系统备份允许）。若你在系统设置中开启了云备份，操作系统可能在执行备份时把应用数据一并纳入并由系统上传到你自己的云账号。这一传输由系统与你的账号设置控制，应用自身不发起、不干涉。你可以通过在系统设置中关闭云备份来阻止此类传输。

八、数据删除

- 你可以在系统「应用管理」（设置 → 应用 → 菲特）中清除本应用数据，或卸载本应用，这将删除设备上的全部本地数据。
- 退出登录会清除本机登录状态（登录令牌与会话快照）；本机业务数据（目标、计划、训练记录、用户资料）保留在设备上，不会被退出操作删除。
- 云端副本：当前版本未提供应用内删除云端数据的入口；如需删除云端快照，请通过第十一节的联系方式提出，我们会在核实账号身份后处理。
- 建议在清除或卸载前先登录并完成云同步，以便在云端保留可恢复的数据副本。

九、未成年人

本应用是通用的健身训练记录工具，不面向 14 周岁以下儿童专门设计。若你是未成年人，请在监护人指导下使用。

十、政策更新

本政策可能随版本更新而调整。任何涉及数据采集、权限或联网行为的变化，都会先更新本政策并同步应用内提示，我们不会在你不知情的情况下改变数据处理方式。
